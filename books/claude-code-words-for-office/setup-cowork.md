まず**ターミナルを使わずに AI に作業させる方法**から始めます。これが **Claude Cowork（クロード・コワーク）** です。

:::message
**Claude Cowork とは**
Claude Code と同じ「自分で手を動かす AI」の仕組みを、**黒い画面（ターミナル）なしで**使えるようにしたものです。指定したフォルダの中のファイルを、AI が実際に読んで・直して・作ります。

2026年1月に登場した機能で、**有料プラン（Pro / Max / Team / Enterprise）が必要**です。
:::

---

## Chat / Cowork / Claude Code の違い

3つあって混乱しがちなので、先に整理します。

| | やること | 画面 | 向いている人 |
| --- | --- | --- | --- |
| **Chat** | 質問に答える。文章を書く | 普通のチャット | 全員 |
| **Cowork** | **ファイルを実際に操作して作業する** | 普通のアプリ画面 | **事務職・非エンジニア** |
| **Claude Code** | 同じことをターミナルで | 黒い画面 | エンジニア |

事務作業なら **Cowork** です。Claude Code を無理に覚える必要はありません。

:::message
Chat と Cowork は**同じ入力欄から切り替えます**。メッセージ入力欄の左下で「Cowork」を選ぶと作業モード、「Chat」を選ぶと普通の会話に戻ります。
:::

### 使い分けの目安

| こんなとき | 使うもの |
| --- | --- |
| 文章の下書き、要約、翻訳、相談 | **Chat**（軽くて速い） |
| 30個のファイルを整理・集計・変換 | **Cowork** |
| Excel を数式つきで作る、資料を大量に作る | **Cowork** |

:::message alert
**Cowork は Chat より利用量（トークン）を多く消費します。** 単純な質問は Chat で済ませたほうが、上限に当たりにくくなります。
:::

## 5ステップで始める

所要時間は10分程度です。

### ステップ1: Claude Desktop をインストールする

[claude.com/download](https://claude.com/download) から、macOS 版または Windows 版をダウンロードしてインストールします。

:::message
Cowork は Web版（claude.ai）やスマホアプリでも使えますが、**自分のパソコンの中のファイルを直接触れるのはデスクトップアプリだけ**です。事務作業なら、まずデスクトップアプリを入れてください。

Windows の方は、Cowork に**最新版が必要**です。古いバージョンだとメニューに出てこないので、更新してください。
:::

### ステップ2: ログインしてプランを確認する

Cowork は有料プラン（Pro / Max / Team / Enterprise）の機能です。無料プランではメニューに出てきません。

会社アカウント（Team / Enterprise）の場合、**管理者が Cowork を無効にしている**こともあります。見つからないときは情シスに確認してください。

### ステップ3: 「Cowork」に切り替える

メッセージの入力欄の左下に「Chat / Cowork」の切り替えがあります。**Cowork を選びます。**

### ステップ4: フォルダを接続する（一番大事）

Cowork は、**あなたが接続したフォルダの中だけ**を読み書きできます。接続していないフォルダには、一切触れません。

![壁に空いた1つの窓から、接続した1つのフォルダだけを差し出す](/images/claude-code-words-for-office/09-one-window-wall.png)

**これがあなたの一番強い安全装置です。** どのフォルダを接続するかが、そのまま「AI に許す範囲」になります。

:::message alert
**接続してはいけないフォルダ**

- デスクトップ全体、書類フォルダ全体、ホームフォルダ全体（`~` 直下）
- パスワードや鍵ファイルが入っているフォルダ
- 顧客の個人情報が入っているフォルダ（作業に必要な場合を除く）

「とりあえず全部」と接続すると、安全装置が無くなります。**必要な1フォルダだけ**接続してください。
:::

具体的な手順は次の章（準備②）で扱います。

### ステップ5: 最初の指示を出す

日本語でそのまま書けます。**専門用語は不要です。**

安全な練習用（何も変えない指示）から始めるのがおすすめです。

```
このフォルダに何のファイルが入っているか、一覧と概要を日本語で教えて
```

うまく動いたら、次に**作る指示**を試します。

```
このフォルダの Excel ファイルを全部読んで、
月別の合計をまとめた新しい Excel を1つ作って
```

## 承認モードを理解する（重要）

Cowork には、**AI がどこまで勝手にやってよいか**を決める3つのモードがあります。入力欄のモード選択でいつでも変更できます。

| モード | 動き | おすすめ度 |
| --- | --- | --- |
| **Manual（手動で承認）** | 操作のたびに聞いてくる | ⭐ **最初はこれ** |
| **Auto（自動）** | AI が安全性を自動チェックして進める。ただし**すべての操作は実行前にチェックされる** | 慣れてから |
| **Skip all approvals** | 何も聞かず全部実行する | ⚠️ 非推奨 |

:::message
**Auto モードについて**
公式ドキュメントには、Auto でも「フォルダの追加接続」「ファイルの削除」「定期タスクの作成」など**重要な操作は自動承認されない**と明記されています。また Auto は安全チェックのぶん**利用量を多く消費**します。

ただし公式も「どのモードもあなたの判断の代わりにはならない」と書いています。**お金・送信・重要ファイルが絡む作業では Manual に戻してください。**
:::

:::message alert
**削除には必ず確認が入ります。**
Cowork では、ファイルを完全に削除する前に必ず許可を求める仕様になっています（Deletion protection）。逆に言えば、**削除の確認が出たときは本気で読むべき**ということです。
:::

## 作業中に画面で起きること

Cowork に指示を出すと、AI はこう動きます。

1. 依頼を分析して**計画を立てる**
2. 必要なら作業を**小さなタスクに分割**する
3. Anthropic のサーバー上の隔離された環境でコマンドやコードを実行する
4. 必要に応じて**複数の作業を並行**して進める
5. 完成した成果物をセッションに届ける（プレビューと保存ができる）

途中で口を出せます。**「そこは違う、こうして」と日本語で割り込んでよい**設計です。

:::message
**AI の作業はサーバー上で動きます。** だからノートパソコンを閉じても作業は続きます。ただし**あなたのパソコンの中のファイルを触るときだけ**、デスクトップアプリを経由します。つまり**ローカルファイルを扱う作業中は、デスクトップアプリを開いたままにしておく**必要があります。
:::

## 全セッションに共通のルールを設定する

毎回同じことを言わなくて済むように、**共通の指示**を設定できます。

**設定 > Cowork**（[claude.ai/settings/cowork](https://claude.ai/settings/cowork)）から「Global instructions」を編集します。

事務職の方におすすめの内容：

```
- 日本語で説明してください
- 私はプログラミングをしません。専門用語は避けて説明してください
- ファイルを削除・上書きする前に、必ず内容を説明して確認を取ってください
- 元のファイルは書き換えず、新しいファイルとして作ってください
- パスワードや認証情報が入ったファイルは開かないでください
- 顧客の個人情報は成果物に含めないでください
```

:::message
**4番目の「元のファイルは書き換えず新規作成」が特に効きます。** 事故のほとんどが「上書き」なので、これを標準ルールにしておくと安心度が大きく変わります。
:::

## 定期実行（スケジュール）

「毎週月曜に集計する」のような**繰り返し作業を自動化**できます。

Cowork の入力欄で `/schedule` と入力するか、左サイドバーの「Scheduled」から作成・管理します。

:::message
定期タスクはサーバー上で動くので、**パソコンの電源が入っていなくても実行されます**。逆に言うと、ローカルフォルダを触る作業は定期実行に向きません。
:::

## うまくいかないときの確認ポイント

| 症状 | 確認すること |
| --- | --- |
| メニューに Cowork がない | 有料プランか / アプリが最新版か / 管理者が無効化していないか |
| ファイルが見つからないと言われる | **そのフォルダを接続したか** |
| 成果物がどこにあるか分からない | AI が作業完了時に伝えた保存場所を確認する。分からなければ「どこに保存した？」と聞く |
| すぐに利用上限に当たる | 簡単な作業は Chat に回す。関連作業は1セッションにまとめる |
