AI に作業させるときの**準備の8割はフォルダ設計**です。ここが決まっていれば、事故はほぼ起きません。

---

## なぜフォルダ設計が重要なのか

前の章で説明したとおり、AI が触れるのは**接続したフォルダの中だけ**です。

つまり、こうなります。

| フォルダの接続の仕方 | 結果 |
| --- | --- |
| 書類フォルダ全体を接続 | AI が全部触れる。**安全装置が消える** |
| 作業用フォルダ1つだけを接続 | 万一暴走しても**そのフォルダの中で終わる** |

**フォルダを分けることが、そのままセキュリティ対策になります。**

---

## おすすめのフォルダ構成

「AI 作業専用の場所」を1つ作るのが基本です。

```
書類/
├── AI作業/                    ← ここだけ接続する
│   ├── 月次集計/
│   │   ├── 入力/              ← 元データを置く（コピー）
│   │   └── 出力/              ← AI が作ったものが入る
│   └── 議事録整理/
│       ├── 入力/
│       └── 出力/
│
├── 契約書/                    ← 接続しない
├── 人事/                      ← 接続しない
└── パスワード関係/            ← 絶対に接続しない
```

ポイントは3つです。

### ① 元データは「コピー」を置く

原本を AI に触らせません。**コピーを `入力/` に置いてから作業させます**。

![原本は金庫にしまい、コピーだけを機械に入れて、出力は別の籠で受ける](/images/claude-code-words-for-office/10-original-and-copy.png)

これだけで「元ファイルが壊れる」という事故が構造的に起きなくなります。

:::message
「コピーするのが面倒」と思うかもしれませんが、**Cowork にコピーを頼めます**。

```
契約書フォルダの2026年6月分を、AI作業/月次集計/入力/ にコピーして
```

ただしこれには両方のフォルダの接続が必要になるので、最初は自分の手でコピーするのが安全です。
:::

### ② 入力と出力を分ける

AI が作ったものと元データが混ざると、**どれが原本か分からなくなります**。フォルダで物理的に分けるのが一番確実です。

### ③ 案件ごとにフォルダを分ける

「月次集計」と「議事録整理」を同じフォルダに入れると、AI が関係ないファイルまで読みます。**読む量が増えると、遅くなり・高くなり・間違いが増えます。**

## フォルダの作り方（普通の操作です）

ターミナルは不要です。いつもの操作で作れます。

### Mac の場合

1. Finder を開く
2. 作りたい場所（書類など）を開く
3. 右クリック → **「新規フォルダ」**
4. 名前を入力

### Windows の場合

1. エクスプローラーを開く
2. 作りたい場所を開く
3. 右クリック → **「新規作成」→「フォルダー」**
4. 名前を入力

:::message
**フォルダ名は日本語で大丈夫です。** ただし次の文字は避けてください。トラブルの元になります。

- スペース（半角の空白）→ `月次_集計` のようにアンダースコアを使う
- 記号 `/ \ : * ? " < > |`
- 絵文字
:::

## フォルダを Cowork に接続する

Claude Desktop で、Cowork モードにしたあと**フォルダを選択します**。

:::message
ボタンの名前や位置はバージョンによって変わるため、この本では断定しません。入力欄の周辺に**フォルダやファイルを指定する箇所**があります。見つからない場合は、Chat で「Cowork でフォルダを接続する手順を教えて」と聞くのが確実です。
:::

接続すると、**そのフォルダを AI が読み書きできる状態**になります。

:::message alert
**接続は「許可を与える」操作です。**
一度接続したフォルダは、そのセッションの間ずっと読み書きできます。作業が終わったら、必要のないフォルダは接続を外す習慣をつけてください。

また、**Auto モードでも「フォルダの追加接続」は自動承認されません**。AI が「このフォルダも接続させて」と求めてきたら、それは重要な確認です。理由を確かめてください。
:::

## プロジェクトとは何か

**一言でいうと**: 関連する作業をまとめておく「専用の作業部屋」。

普通のセッションは、終われば内容が散らばります。プロジェクトを作ると、その中に以下が**まとまって残ります**。

| 持てるもの | 意味 |
| --- | --- |
| **ファイル** | その案件の資料 |
| **リンク** | 参照する URL |
| **指示（instructions）** | この案件専用のルール |
| **メモリ（memory）** | 前回の内容を覚えている |

![前回の決定が壁に貼られた小部屋に入る。外の紙は一枚きりで残らない](/images/claude-code-words-for-office/18-project-room.png)

:::message
**Cowork でメモリ（記憶）が使えるのはプロジェクトの中だけ**です。「毎回説明し直すのが面倒」な繰り返し作業は、プロジェクトを作る価値があります。

なお、Chat での記憶は Cowork には引き継がれません（2026年7月時点）。
:::

### プロジェクトを作るべき作業／作らなくていい作業

| 作業 | プロジェクト |
| --- | --- |
| 毎月の請求書処理、月次レポート、定例議事録 | **作る**（毎回同じルールを使う） |
| 一度きりのファイル整理、単発の変換 | 作らない（普通のセッションで十分） |

### プロジェクトの作り方

Cowork の画面のサイドバーから新しいプロジェクトを作成し、名前をつけて、関連ファイルと指示を登録します。

**プロジェクトの指示に書くとよいこと**（月次請求書処理の例）：

```
【この案件について】
毎月、入力フォルダにある請求書PDFを集計して、Excelにまとめる作業です。

【手順】
1. 入力/ の中のPDFを全部読む
2. 日付・取引先・金額を抽出する
3. 出力/ に「請求書一覧_YYYY-MM.xlsx」として保存する

【ルール】
- 入力フォルダのファイルは絶対に変更・削除しない
- 金額が読み取れないものは空欄にして、最後に「確認が必要な項目」として一覧にする
- 取引先の担当者名などの個人情報は出力に含めない
```

:::message
**「読み取れないものは空欄にして最後に報告」というルールが効きます。**
これがないと、AI は空欄を嫌って**推測で埋めてしまう**ことがあります。金額を推測されるのは事務作業では致命的です。「分からないときは分からないと書く」と明示してください。
:::

## フォルダ単位の指示（Folder instructions）

プロジェクトとは別に、**接続したフォルダごとに指示**を持たせることもできます。そのフォルダで作業するときだけ効くルールです。

「このフォルダのファイル名は `YYYY-MM-DD_取引先名` の形式にする」のような、**場所に紐づくルール**に向いています。

:::message
AI が作業中にこの指示を自分で更新することもあります。「前回こう決めたよね」が引き継がれるので便利ですが、**勝手に変わっている場合もある**ので、時々中身を確認してください。
:::

---

## 3つの指示の使い分け

指示を書ける場所が3つあって混乱しやすいので、整理します。

| 場所 | 効く範囲 | 書く内容 |
| --- | --- | --- |
| **Global instructions**（設定 > Cowork） | **すべての作業** | 「日本語で」「元ファイルは書き換えない」などの普遍的ルール |
| **プロジェクトの指示** | その案件だけ | その案件の手順とルール |
| **Folder instructions** | そのフォルダだけ | ファイル名の規則など、場所に紐づくもの |

迷ったら **Global に書く**のが実用的です。範囲が広くて損はありません。

## 最初にやることチェックリスト

- [ ] 「AI作業」フォルダを1つ作る
- [ ] その中に案件ごとのフォルダを作り、`入力/` と `出力/` に分ける
- [ ] 元データは**コピー**を `入力/` に置く
- [ ] Cowork に**そのフォルダだけ**を接続する
