Claude Code を起動して最初に出会う言葉たちです。**AI との会話そのものに関する言葉**をここにまとめました。

---

## ターミナル / コンソール（Terminal / Console）

**一言でいうと**: 文字だけでパソコンに命令する画面。あの黒い（または白い）画面のこと。

Excel や Word が「ボタンを押して操作する道具」なら、ターミナルは「**命令を文字で書いて操作する道具**」です。できることは同じで、入口が違うだけです。

:::message
「コンソール」「シェル」「コマンドライン」もほぼ同じものを指します。厳密には違いますが、**事務作業の場面では区別しなくて大丈夫**です。
:::

## CLI（シーエルアイ / Command Line Interface）

**一言でいうと**: 文字で操作する方式のこと。ターミナルで動く道具は「CLI ツール」と呼ばれます。

Claude Code も CLI ツールです。反対語は **GUI**（ジーユーアイ）で、こちらはマウスでボタンを押す普通のアプリのことです。

| 呼び方 | 操作方法 | 例 |
| --- | --- | --- |
| GUI | マウスでクリック | Excel、Chrome、Finder |
| CLI | 文字で命令 | Claude Code、git |

## プロンプト（Prompt）

**一言でいうと**: AI への指示文。あなたが打ち込む日本語の文章そのもの。

「プロンプトを工夫する」＝「**頼み方を工夫する**」という意味です。難しい呪文ではありません。

:::message
まぎらわしい注意点として、ターミナルの用語では「プロンプト」は**入力待ちの記号**（`$` や `%`）も指します。AI の話をしているときは前者、ターミナルの話なら後者です。
:::

## コンテキスト（Context）

**一言でいうと**: AI が今おぼえている情報の全体。会話の履歴＋読んだファイルの中身。

AI の**短期記憶**だと考えてください。ここに入っていない情報について、AI は知りません。

だから「さっき言ったのに忘れてる」ということが起きます。人間が忘れるのと違って、**そもそも記憶に入る枠に上限がある**のが原因です。

## コンテキストウィンドウ（Context Window）

**一言でいうと**: その短期記憶の上限サイズ。

机の広さのようなものです。書類を広げすぎると、古い書類が机から落ちます。**長く会話を続けると、最初のほうの内容が押し出されて忘れられます**。

対策は簡単で、**話題が変わったら新しいセッションを始める**ことです。

## セッション（Session）

**一言でいうと**: AI との1回の会話のかたまり。起動してから終了するまで。

セッションを新しくすると、コンテキスト（短期記憶）は空になります。「一度リセットして最初から説明し直す」＝新しいセッションを始める、です。

:::message
うまく動かなくなったときの最初の対処法は、**新しいセッションで頼み直す**ことです。机を片付けるのと同じで、これだけで直る場合がかなりあります。
:::

## トークン（Token）

**一言でいうと**: AI が文章を数えるときの単位。文字数のようなもの。

だいたい**日本語1文字 ≒ 1トークン弱**、英語1単語 ≒ 1トークン強です。「トークンを消費する」＝「**AI の利用量を使っている**」という意味で、料金や上限に関わります。

長いファイルを何十個も読ませると、トークンを大量に使います。**必要なファイルだけ渡すほうが速くて安い**、という話の背景がこれです。

## モデル（Model）

**一言でいうと**: AI の頭脳の種類。名前とバージョンがある。

Claude には Opus、Sonnet、Haiku などの種類があります。ざっくり言えば：

| 種類 | 性格 | 向いている作業 |
| --- | --- | --- |
| Opus | 賢いが遅い・高い | 難しい判断、設計 |
| Sonnet | バランス型 | 普段の作業 |
| Haiku | 速くて安い | 単純な繰り返し |

## エージェント（Agent）

**一言でいうと**: 自分で考えて手を動かす AI。ただ答えるだけでなく作業する AI のこと。

チャットの AI は「答えを返す」だけですが、エージェントは「**ファイルを開く → 直す → 確認する**」を自分で順番にやります。Claude Code はエージェントです。

だから許可を求めてくるわけです。手を動かす相手だからです。

## ツール（Tool）

**一言でいうと**: AI が使える道具。ファイルを読む、コマンドを実行する、などの機能。

画面に `Read` `Edit` `Bash` などと出るのは、**AI が今どの道具を使ったか**の表示です。詳しくは第3部で扱います。

## Skill（スキル）

**一言でいうと**: AI に覚えさせた作業手順書。

「請求書の処理手順」のような決まった作業を文書にしておくと、AI が必要なときに読んで、その手順どおりに動きます。**マニュアルを渡しておく**のと同じ発想です。

## MCP（エムシーピー）

**一言でいうと**: AI を外部サービスにつなぐ接続規格。

これがあると、AI が Google Drive や Slack などを直接操作できるようになります。**AI に外線電話をつけるようなもの**だと考えてください。名前は難しいですが、使う側は「つながっているかどうか」だけ意識すれば十分です。

## CLAUDE.md（クロードドットエムディー）

**一言でいうと**: AI が毎回自動で読む、あなた専用のルールブック。

「日本語で答えて」「このフォルダは触らないで」といった**毎回言いたくないこと**を書いておくファイルです。毎回のお願いを省略できます。

---

## この章のまとめ

| 覚えること | 実用的な意味 |
| --- | --- |
| コンテキストには上限がある | 長い会話は忘れる。**新セッションで直る** |
| Claude Code はエージェント | 実際に手を動かすので、許可を聞いてくる |
| CLAUDE.md はルールブック | 毎回言うのが面倒なことはここに書く |

次の章では、**ファイルとプロジェクトに関する言葉**を扱います。
