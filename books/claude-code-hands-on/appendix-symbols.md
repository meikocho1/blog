## 記号の逆引き

### 場所を表す記号

| 記号 | 読み | 意味 |
| --- | --- | --- |
| `.` | ドット | **今いるフォルダ** |
| `..` | ドットドット | **1つ上のフォルダ** |
| `./` | ドットスラッシュ | 今いるフォルダの中の〜 |
| `~` | チルダ | **自分のホームフォルダ**（`/Users/あなたの名前`） |
| `/` | スラッシュ | フォルダの区切り。先頭にあると一番上（ルート） |
| `-` | ハイフン | 「直前にいた場所」（`cd -` のとき） |

:::message
`rm -rf .` は「今いるフォルダを丸ごと消す」、`rm -rf /` は「パソコン全体を消す」という意味になります。**ドット1つの違いが致命的**なので、`rm` の対象は必ず声に出して読んでください。
:::

![ほぼ同じ2枚の札。片方は小さなトレイ、片方は巨大な棚を指している](/images/claude-code-words-for-office/28-one-character-apart.png)

:::message alert
見た目がほぼ同じ2つの指示が、**片方は小皿を空にするだけ、もう片方は建物全体を空にする**——という差になります。だから「コマンド名」ではなく**対象を確認する**のが実務です。
:::

### まとめて指定する記号（ワイルドカード）

| 記号 | 意味 | 例 |
| --- | --- | --- |
| `*` | **何文字でも当てはまる** | `*.xlsx` = Excel ファイル全部 |
| `?` | 1文字だけ当てはまる | `2026-0?.md` |
| `**` | フォルダを何階層でもまたぐ | `**/*.md` |

`*` は Excel の検索やファイル名検索と同じ感覚です。

### つなぎの記号

| 記号 | 意味 |
| --- | --- |
| `|` | パイプ。**左の結果を右に渡す** |
| `>` | 上書き保存（**元の中身は消える**） |
| `>>` | 追記（元の中身は残る） |
| `&&` | 前が成功したら次を実行 |
| `;` | 成功・失敗にかかわらず次を実行 |
| `2>&1` | エラーの表示も一緒にまとめる |

例：
```
ls | wc -l
```
「一覧を出して、その行数を数える」＝**ファイルの個数を数える**、という意味になります。

### オプションの記号

| 記号 | 意味 |
| --- | --- |
| `-` | 短いオプション（`-l` `-r` など、1文字） |
| `--` | 長いオプション（`--help` `--force` など） |
| `-la` | 短いオプションはくっつけて書ける（`-l` と `-a`） |

**危険なオプションだけ覚えれば十分です。**

| オプション | 意味 | 注意 |
| --- | --- | --- |
| `-f` / `--force` | **強制。確認しない** | ⚠️ |
| `-r` / `-R` | フォルダの中まで再帰的に | ⚠️（`rm` と組むと危険） |
| `-y` / `--yes` | 質問に全部 Yes と答える | ⚠️ |
| `--hard` | 変更を捨てる（`git reset`） | 🔴 |
| `--prod` | 本番環境に対して実行 | 🔴 |

### 行頭の記号

| 記号 | 意味 |
| --- | --- |
| `$` / `%` | **入力待ちの印**。この後ろがコマンド本体（`$` 自体は打たない） |
| `#` | コメント（説明文）。実行されない |
| `●` | Claude Code が作業した印 |
| `⎿` | その作業の結果 |

:::message
ネットの記事にある `$ ls -la` をコピーするときは、**`$ ` を除いて `ls -la` だけ**をコピーします。よくある詰まりポイントです。
:::

## エラー文の逆引き

英語のエラー文は、**ほとんどが数パターンの繰り返し**です。

### `command not found`

**意味**: そんな命令はありません。

**原因**: 打ち間違い、またはその道具が入っていない。

**対応**: そのまま AI に貼れば直してくれます。
```
これが出ました: command not found: nmp
```

### `No such file or directory`

**意味**: そのファイル（フォルダ）が見つかりません。

**原因**: ほぼ**場所の間違い**です。今いるフォルダが想定と違います。

**対応**:
```
pwd で今どこにいるか確認して、正しいパスでやり直して
```

### `Permission denied`

**意味**: 権限がありません。

**原因**: 触ってはいけない場所、または読み取り専用のファイル。

**対応**: `sudo` を付けて解決したくなりますが、**まず「なぜそこを触るのか」を確認してください**。多くの場合、場所が間違っています。

### `Address already in use` / `port 3000 is already in use`

**意味**: その番号（ポート）はすでに使われています。

**原因**: 同じアプリを二重に起動している。

**対応**: 前に起動したものが動いたままです。
```
3000番ポートを使っているプロセスを確認して止めて
```

### `fatal: not a git repository`

**意味**: ここは Git で管理されているフォルダではありません。

**原因**: 別のフォルダにいる。

**対応**: プロジェクトのフォルダに移動してからやり直します。

### `npm ERR!`

**意味**: 部品の取り寄せに失敗しました。

**原因**: ネットワーク、バージョンの不一致など様々。

**対応**: **エラー全文をコピーして AI に貼る**のが最短です。抜粋せず全部貼ってください。

### `merge conflict` / `CONFLICT`

**意味**: 2人（または2つの作業）が同じ場所を別々に書き換えたため、どちらを採用するか決められません。

**対応**: 自分で解決しようとせず、
```
コンフリクトの内容を日本語で説明して。どちらを残すべきか教えて
```

### `EACCES` / `ENOENT` / `EAI_AGAIN`

**意味**: それぞれ「権限がない」「ファイルがない」「ネットワークが不調」の略号です。

**対応**: `E` で始まる大文字の英数字は**エラーの略号**です。意味を覚える必要はありません。そのまま貼ってください。

---

## エラー対応の万能テンプレート

エラー文を1つも覚えなくても、これで進めます。

```
こういうエラーが出ました。原因と対処を日本語で説明して、
危険な操作を含まない範囲で直してください。

（ここにエラー全文を貼る）
```

**「危険な操作を含まない範囲で」の一文が効きます。** これがないと、AI が手っ取り早く `rm -rf` や `sudo` を提案してくることがあります。

---

## おわりに

この本の内容を1文にまとめると、こうなります。

:::message
**知らない単語が出てきても構わない。「何が変わるのか」「戻せるのか」だけ分かれば、AI は安全に使える。**
:::

そして分からないときの正解はいつも同じで、**日本語で聞き返すこと**です。Claude Code は聞き返されることを前提に作られています。遠慮なく止めてください。
