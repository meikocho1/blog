## この本は誰のためのものか

**Claude Code を少し触ってみて、画面に流れる英語で止まってしまった人**のための本です。

- ターミナル（黒い画面）で Claude Code を動かしてみた
- `● Bash(grep -rn "請求書" .)` のような表示が読めない
- `rm -rf` や `git push` の許可を求められて、押せずに固まった
- エラーの赤い文字を見て手が止まった

プログラミングを覚える必要はありません。**読めるようになれば十分**です。

:::message
**事務職・非エンジニアの方へ**

この本には Git や Linux コマンドが出てきます。もしあなたが **Claude Cowork（ターミナルを使わない方）** で作業したいだけなら、この本は不要です。先に姉妹編の『**AIが何をしているか分かる本 — 事務職のための Claude Cowork 入門**』を読んでください。

Cowork では、この本の内容を知らなくても作業できます。
:::

## Cowork と Claude Code の違い

| | 画面 | この本の必要性 |
| --- | --- | --- |
| **Claude Cowork** | 普通のアプリ画面 | 不要（姉妹編で足ります） |
| **Claude Code** | **ターミナル（黒い画面）** | **必要** |

中身の仕組みは同じです。違うのは**あなたが見る画面**だけです。そしてターミナルの画面には、コマンドがそのまま表示されます。だから読み方が必要になります。

## この本で一番大事なこと

コマンドを暗記する必要はありません。次の1つを見分けられれば十分です。

:::message
**そのコマンドは「見るだけ」か、「変える」か。**

- **見るだけ** … 読む、探す、数える。元に戻す必要すらない
- **変える** … 作る、書き換える、消す、外に送る。**ここだけ気をつける**
:::

3章がすべて「見るだけ」、4章がすべて「変える」で構成されています。この区別が本書の背骨です。

それでは1章から始めましょう。
