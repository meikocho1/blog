ここから、AI が画面に表示するコマンドを見ていきます。

この章のコマンドは**すべて「見るだけ」**です。ファイルを1つも変えません。だから、これらが出てきたときは**安心して先に進めてよい**と判断できます。

![ガラスの蓋の上から覗くだけ。手は後ろに組んだまま中には入れない](/images/claude-code-words-for-office/15-hands-behind-back.png)

:::message
コマンドは「命令」＋「オプション」＋「対象」という形をしています。

```
grep -rn "請求書" ./documents
 ↑     ↑    ↑        ↑
命令  オプション 探す言葉   探す場所
```
:::

---

## ls — 一覧する（list）

**やること**: フォルダの中身を並べて表示する。エクスプローラーでフォルダを開くのと同じ。

```
ls
ls -la documents
```

| よく付くオプション | 意味 |
| --- | --- |
| `-l` | 詳しく（サイズや日付も） |
| `-a` | 隠しファイルも含めて全部 |
| `-la` | 上の両方 |

## pwd — 今どこにいるか（print working directory）

**やること**: 現在いるフォルダの住所を表示する。

```
pwd
→ /Users/tanaka/Documents/project
```

AI が迷子になっていないか確認するときに使われます。

## cd — 移動する（change directory）

**やること**: フォルダを移動する。ダブルクリックでフォルダを開くのと同じ。

```
cd documents
cd ..
```

`..`（ドット2つ）は「**1つ上のフォルダ**」という意味です。

:::message
`cd` は移動だけなので何も変えませんが、**このあとに続くコマンドの対象が変わります**。「どこにいるか」は常に気にする価値があります。
:::

## cat — 中身を全部出す（concatenate）

**やること**: ファイルの中身をそのまま画面に表示する。

```
cat README.md
```

名前は変ですが（由来は「連結する」）、実質「**開いて見せる**」コマンドです。

## head / tail — 先頭だけ / 末尾だけ

**やること**: ファイルの最初の数行、最後の数行だけを表示する。

```
head -20 log.txt    # 最初の20行
tail -50 log.txt    # 最後の50行
```

長いログを見るとき、**最後の数行にエラーが書いてあることが多い**ので `tail` がよく使われます。

## grep — 探す（検索）

**やること**: ファイルの中から、指定した文字が含まれる行を探す。

**Excel の検索や Ctrl+F と同じもの**です。事務作業では一番よく見るコマンドになるはずです。

```
grep -rn "請求書" ./documents
```

これは「documents フォルダ以下の全ファイルから『請求書』という文字を含む行を、行番号つきで探す」という意味です。結果はこう出ます。

```
documents/2026-06.md:12: 請求書のテンプレートを更新
documents/2026-07.md:3:  請求書の締め日
```

`ファイル名:行番号: 内容` という形式です。

![大きな紙の山から該当する一行だけを引き出す。山は崩れない](/images/claude-code-words-for-office/25-pull-one-line.png)

**山は崩れません。** 検索は結果を1行取り出すだけで、元のファイルには何もしません。

| よく付くオプション | 意味 |
| --- | --- |
| `-r` | フォルダの中を**まるごと**探す |
| `-n` | **行番号**も表示する |
| `-i` | 大文字小文字を**区別しない** |
| `-l` | 該当した**ファイル名だけ**を出す |

## rg — 速い grep（ripgrep）

**やること**: `grep` と同じ。中身の検索。ただしずっと速い。

Claude Code は `grep` より `rg` を好んで使います。**見たら「検索だな」と思ってください**。役割は完全に同じです。

## find — ファイルを名前で探す

**やること**: 名前や条件でファイルそのものを探す。中身は見ない。

```
find . -name "*.xlsx"
```

「今いる場所（`.`）以下から、名前が `.xlsx` で終わるファイルを探す」という意味です。

| `grep` と `find` の違い | 探すもの |
| --- | --- |
| `grep` | ファイルの**中身** |
| `find` | ファイルの**名前** |

:::message
Mac の「Finder」とは別物ですが、**役割は似ています**（探すための道具）。名前が紛らわしいだけです。
:::

## wc — 数える（word count）

**やること**: 行数・単語数・文字数を数える。

```
wc -l list.csv
→ 1523 list.csv
```

`-l` は行数です。「何件あるか」を数えるときに使われます。

## git status — 今の状態を確認する

**やること**: どのファイルが変更されているかを一覧する。

**AI に作業を頼んだ後、これで「何が触られたか」が分かります**。この本の中で覚える価値が最も高いコマンドの1つです。

```
git status
```

## git diff — 変更内容を確認する

**やること**: 変更前と変更後の違いを表示する。

```
git diff
```

`-` が削除、`+` が追加です（第7章参照）。**AI が何を書き換えたのか、これで自分の目で確認できます。**

## git log — 履歴を見る

**やること**: 過去のコミット（セーブポイント）の一覧を表示する。

```
git log --oneline
```

## echo — そのまま表示する

**やること**: 文字をそのまま画面に出す。動作確認のために使われる。

```
echo "テスト"
→ テスト
```

## which / type — 道具があるか確認する

**やること**: そのコマンドがインストール済みかを確認する。

```
which node
```

## この章のまとめ

**この一覧に載っているコマンドが出てきたら、内容を細かく読まなくても Yes で構いません。**

| コマンド | ひとこと |
| --- | --- |
| `ls` | 一覧 |
| `pwd` | 今どこ |
| `cd` | 移動 |
| `cat` / `head` / `tail` | 中身を見る |
| `grep` / `rg` | 中身を検索（Ctrl+F） |
| `find` | 名前で探す |
| `wc` | 数える |
| `git status` | 何が変わったか |
| `git diff` | どう変わったか |
| `git log` | 履歴 |

次の章は逆で、**気をつけるべきコマンド**です。
