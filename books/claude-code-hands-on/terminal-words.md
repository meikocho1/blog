黒い画面そのものに関する言葉です。**ここが分かると、以降の章の前提が揃います。**

---

## ターミナル / コンソール（Terminal / Console）

**一言でいうと**: 文字だけでパソコンに命令する画面。あの黒い（または白い）画面のこと。

Excel や Word が「ボタンを押して操作する道具」なら、ターミナルは「**命令を文字で書いて操作する道具**」です。できることは同じで、入口が違うだけです。

:::message
「コンソール」「シェル」「コマンドライン」もほぼ同じものを指します。厳密には違いますが、**実務では区別しなくて大丈夫**です。
:::

## シェル（Shell）

**一言でいうと**: あなたが打った文字を解釈して実行するプログラム。ターミナルの中身。

種類があり、Mac の既定は `zsh`（ズィーシェル）、Linux では `bash`（バッシュ）が多いです。`fish` を使っている人もいます。

**どれを使っているかは、ネット記事のコマンドが動かないときだけ関係します。**

## CLI（シーエルアイ / Command Line Interface）

**一言でいうと**: 文字で操作する方式のこと。ターミナルで動く道具は「CLI ツール」と呼ばれます。

Claude Code も CLI ツールです。反対語は **GUI**（ジーユーアイ）で、こちらはマウスでボタンを押す普通のアプリです。

| 呼び方 | 操作方法 | 例 |
| --- | --- | --- |
| GUI | マウスでクリック | Excel、Chrome、Finder |
| CLI | 文字で命令 | Claude Code、git |

---

## プロンプト（Prompt）— 2つの意味

**ややこしい注意点です。** この言葉は文脈で意味が変わります。

| 文脈 | 意味 |
| --- | --- |
| **AI の話** | AI への指示文（あなたが打つ日本語） |
| **ターミナルの話** | **入力待ちの記号**（`$` や `%` や `>`） |

ネット記事の `$ ls -la` の `$` は後者です。**`$ ` は打ちません。**

![先頭の記号だけを点線に沿って切り落とし、本体だけを残す](/images/claude-code-words-for-office/20-cut-the-prompt-mark.png)

コピーするときは **`$ ` を除いて `ls -la` だけ**をコピーします。**初心者が最初に詰まるポイントです。**

---

## カレントディレクトリ / 作業ディレクトリ（Current Directory）

**一言でいうと**: 今いるフォルダ。「ここ」がどこかということ。

ターミナルには**必ず「今どのフォルダにいるか」という状態があります**。エクスプローラーで開いているフォルダと同じ概念です。

:::message
**「ファイルが見つからない」の原因は、9割これです。** 探している場所が違うだけです。`pwd` で今いる場所を確認できます（3章）。
:::

## パス（Path）と、相対 / 絶対

**一言でいうと**: ファイルの住所。`/` はフォルダの区切り。

![入れ子になった3つの箱。蓋を1つずつ通って一番奥の紙に届く](/images/claude-code-words-for-office/23-nested-boxes.png)

| 種類 | 例 | 意味 |
| --- | --- | --- |
| **相対パス** | `documents/請求書.xlsx` | **今いるフォルダから見て** |
| **絶対パス** | `/Users/tanaka/documents/請求書.xlsx` | 一番上から数えた完全な住所 |

絶対パスは必ず `/` で始まります（Windows なら `C:\`）。

| 記号 | 意味 |
| --- | --- |
| `.` | 今いるフォルダ |
| `..` | 1つ上のフォルダ |
| `~` | 自分のホームフォルダ（`/Users/あなたの名前`） |
| `/` | 区切り。先頭なら一番上（ルート） |

:::message alert
**`.` と `/` の1文字差が致命的になります。**

- `rm -rf .` → 今いるフォルダを丸ごと削除
- `rm -rf /` → **パソコン全体を削除**

削除系の対象は、必ず声に出して読んでください。
:::

## 環境変数（Environment Variable）

**一言でいうと**: パソコンに覚えさせておく設定値。パスワードや接続先を入れる場所。

`.env`（ドットイーエヌブイ）というファイルに書かれることが多く、**中身はパスワードや API キーなどの機密情報**です。

:::message alert
`.env` や鍵ファイル（`~/.ssh` の中）は、**AI に開かせない**のが原則です。一度読み上げると会話の記録に残り、後から消せません。

`CLAUDE.md` にこう書いておけば自動で守られます。

```
.env や鍵ファイルは開かない・中身を出力しない
```
:::

## PATH（環境変数の PATH）

**一言でいうと**: コマンドを探しに行く場所のリスト。

`command not found` の原因はたいていこれです。**「そのプログラムは入っているが、探す場所に入っていない」**という状態です。

紛らわしいですが、前述の「パス（ファイルの住所）」とは別物です。

---

## ログ（Log）

**一言でいうと**: 動作の記録。何が起きたかが時系列で並んだ文章。

エラーの原因はほぼログに書いてあります。**読めなくても構いません。そのままコピーして AI に貼れば十分です。**

## デバッグ（Debug）

**一言でいうと**: うまく動かない原因を探して直す作業。

## エラー（Error）

**一言でいうと**: 失敗の通知。**「壊れた」という意味ではありません。**

赤い文字が出ても慌てなくて大丈夫です。詳しくは付録の逆引きを見てください。

---

## npm / package.json / ビルド

**一言でいうと**: 部品を取り寄せる仕組み・その部品リスト・動く形に組み立てる作業。

| 言葉 | 意味 |
| --- | --- |
| `npm install` | **必要な部品をまとめて取り寄せる**。時間はかかるが通常は安全 |
| `package.json` | 必要な部品のリスト |
| `node_modules` | 取り寄せた部品が入るフォルダ。**消しても入れ直せる** |
| ビルド | 書いたものを、実際に動く形に組み立てる作業 |

:::message
**`node_modules` は消してもいい**という事実は、実務で意外と役に立ちます。`rm -rf node_modules` は見た目が怖いですが、`npm install` で戻ります。
:::
