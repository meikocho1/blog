:::

## 見るだけのコマンド（安全）

### 🟢 `ls`（エルエス）

**見るだけ・安全**

**一言でいうと**: 今いる場所にあるファイルとフォルダの名前を並べて見せる

フォルダを開けて中身を眺めるだけの命令です。机の引き出しを開けて中を見るのと同じで、何も書き換えません。-l を付けると大きさや更新日も一緒に並びます。Claude Code は「今どんなファイルがあるのか」を確かめるため、作業のはじめによく実行します。

```
ls -la
→ -rw-r--r--  1 you  staff  1240  7 25 10:03 README.md
```

| オプション | 意味 |
| --- | --- |
| `-l` | 権限・大きさ・更新日つきの詳しい表で表示 |
| `-a` | 「.」で始まる隠しファイルも表示 |
| `-la` | 詳しい表＋隠しファイルも（いちばんよく見る形） |
| `-lh` | 大きさを 1K / 234M のように読みやすく（-l と併用） |
| `-R` | 中のフォルダまで全部たどって表示 |
| `-t` | 更新が新しい順に並べる |
| `-1` | 1行に1つずつ表示 |

### 🟢 `pwd`（ピーダブリューディー）

**見るだけ・安全**

**一言でいうと**: 今どのフォルダで作業しているかを住所として表示する

print working directory の略です。地図アプリの「現在地」ボタンにあたります。表示するだけで何も変えません。Claude Code が意図しない場所を触っていないか確認するために出てきます。

```
pwd
→ /Users/you/Documents/my-zenn
```

### 🟢 `cd`（シーディー）

**見るだけ・安全**

**一言でいうと**: 作業するフォルダを移動する。中身は何も変わらない

change directory の略です。建物の中で部屋を移動するだけで、荷物は動きません。移動しただけなのでファイルは無傷です。移動できたかは pwd で確かめられます。

```
cd ~/Documents/my-zenn
```

| オプション | 意味 |
| --- | --- |
| `..` | 一つ上のフォルダへ（cd ..） |
| `-` | 直前にいた場所へ戻る（cd -） |
| `~` | 自分のホームフォルダへ（cd ~） |

### 🟢 `cat`（キャット）

**見るだけ・安全**

**一言でいうと**: ファイルの中身を全部そのまま画面に流して見せる

紙を机に一気に広げるような命令です。短いファイル向けで、長いファイルだと画面が流れきってしまうので less や head を使います。読むだけで変更はしませんが、.env や鍵ファイルは中身が画面や記録に残ってしまうため開かせないのが会社ルールです。

```
cat package.json
```

| オプション | 意味 |
| --- | --- |
| `-n` | 行番号を付けて表示 |

### 🟢 `less`（レス）

**見るだけ・安全**

**一言でいうと**: 長いファイルを1画面ずつめくって読むための表示ソフト

本をページ送りで読む感覚の道具です。スペースキーで次のページ、/文字 で検索、q で終了します。ファイルには一切触りません。終わり方が分からず固まってしまう人が多いので、q だけ覚えておけば大丈夫です。

```
less README.md
（読み終わったら q キーで抜ける）
```

| オプション | 意味 |
| --- | --- |
| `-N` | 行番号を表示 |
| `-S` | 長い行を折り返さない |
| `-R` | 色をそのまま表示 |
| `+F` | 追記を待ちながら追いかける（ログ向け） |

### 🟢 `head`（ヘッド）

**見るだけ・安全**

**一言でいうと**: ファイルの先頭だけをちょっと見る（何も指定しないと10行）

本の最初の数ページを立ち読みする感じです。巨大なファイルの形式だけ確かめたいときに使います。読むだけなので安全で、パイプと組んで長い出力の頭だけ見る形もよく出ます。

```
head -n 20 data.csv
```

| オプション | 意味 |
| --- | --- |
| `-n 20` | 先頭20行だけ表示 |
| `-c 200` | 先頭200バイトだけ表示 |

### 🟢 `tail`（テイル）

**見るだけ・安全**

**一言でいうと**: ファイルの末尾だけを見る。ログ確認の定番コマンド

日記の最後のページだけを開くようなものです。-f を付けると新しく書かれた行が出るのを待ち続け、流れるログをそのまま眺められます。止めるときは Ctrl+C。見るだけなのでファイルは変わりません。

```
tail -n 50 server.log
tail -f server.log
```

| オプション | 意味 |
| --- | --- |
| `-n 50` | 末尾50行だけ表示 |
| `-f` | 追記を待ち続けて流し続ける（Ctrl+C で停止） |
| `-c 200` | 末尾200バイトだけ表示 |

### 🟢 `wc`（ダブリューシー）

**見るだけ・安全**

**一言でいうと**: 行数や文字数を数えるだけの命令。件数確認によく使う

word count の略で、原稿の枚数を数えるのと同じ役割です。数えるだけでファイルには触りません。grep の結果を | wc -l に渡して「何件見つかったか」を出す形が最も頻繁に出てきます。

```
wc -l README.md
→ 142 README.md
```

| オプション | 意味 |
| --- | --- |
| `-l` | 行数を数える |
| `-w` | 単語数を数える |
| `-c` | バイト数を数える |
| `-m` | 文字数を数える（日本語向き） |

### 🟢 `grep`（グレップ）

**見るだけ・安全**

**一言でいうと**: たくさんのファイルから文字を探して、該当した行を出す

本の巻末の索引で単語を引くような道具です。「この言葉はどこで使われている？」を調べる基本装備で、見つけた行を表示するだけで書き換えはしません。Claude Code が調べ物をするときに画面へよく流れます。

```
grep -rn "TODO" src/
→ src/app.ts:42:  // TODO: あとで直す
```

| オプション | 意味 |
| --- | --- |
| `-r` | フォルダの中を全部たどって探す |
| `-n` | 何行目かを表示 |
| `-i` | 大文字小文字を区別しない |
| `-l` | 見つかったファイル名だけ表示 |
| `-v` | 逆に、一致しない行を出す |
| `-c` | 件数だけ数える |
| `-E` | 高度な検索記号（正規表現）を使う |
| `-w` | 単語としてぴったり一致するものだけ |
| `-C 3` | 前後3行も一緒に表示 |
| `--include="*.ts"` | 探す対象をファイル名の形で絞る |

### 🟢 `rg`（リップグレップ）

**見るだけ・安全**

**一言でいうと**: grep の高速版。無視設定を尊重しながら中身を探す

ripgrep の略で、grep と同じ「文字を探す」道具です。.gitignore に書かれたファイル、隠しファイル、画像などのデータファイルを自動で飛ばすため、速くて結果も読みやすくなります。散らかった部屋でも「見なくていい箱」を先に除けてから探すイメージです。探すだけで書き換えません。

```
rg "useState" src/
```

| オプション | 意味 |
| --- | --- |
| `-i` | 大文字小文字を区別しない |
| `-n` | 行番号を表示（もともと付く） |
| `-l` | 見つかったファイル名だけ表示 |
| `-t ts` | TypeScript だけなど、種類で絞る |
| `-g "*.md"` | ファイル名の形で絞る |
| `--hidden` | 隠しファイルも探す |
| `-C 3` | 前後3行も表示 |
| `--files` | 探す対象のファイル一覧だけ出す |

### 🟢 `find`（ファインド）

**見るだけ・安全**

**一言でいうと**: 名前や種類などの条件でファイルの置き場所を探し出す

中身ではなく「ファイルそのもの」を探す道具です。図書館の棚をたどって本を探すイメージで、条件に合った場所を並べます。探すだけなら安全ですが、-delete や -exec rm が付くと消す命令に変わるので、その形を見たら止めて確認してください。

```
find . -name "*.md" -type f
```

| オプション | 意味 |
| --- | --- |
| `-name "*.md"` | 名前の形で探す |
| `-iname` | 大文字小文字を区別せず名前で探す |
| `-type f` | ファイルだけ（-type d はフォルダだけ） |
| `-maxdepth 2` | 深さ2段までで打ち切る |
| `-mtime -7` | 7日以内に更新されたものだけ |
| `-size +1M` | 1メガより大きいものだけ |
| `-delete` | 見つけたものを削除する（これが付いていたら止めて確認） |

### 🟢 `fd`（エフディー）

**見るだけ・安全**

**一言でいうと**: find の書きやすい版。探したい言葉を直接書いて探せる

追加でインストールして使う道具です。find . -iname "*報告*" と書く代わりに fd 報告 で済みます。.gitignore と隠しファイルを最初から飛ばし、大文字を書いたときだけ大文字小文字を区別する親切設計です。探して並べるだけなので安全です。

```
fd -e md docs
```

| オプション | 意味 |
| --- | --- |
| `-e md` | 拡張子で絞る |
| `-t f` | ファイルだけ（-t d はフォルダだけ） |
| `-H` | 隠しファイルも含める |
| `-I` | 無視設定（.gitignore）を無効にする |
| `-d 2` | 深さ2段まで |
| `-g` | * を使うグロブ記法で探す |

### 🟢 `tree`（ツリー）

**見るだけ・安全**

**一言でいうと**: フォルダの入れ子構造を枝分かれの図で見せてくれる

家系図のようにフォルダの親子関係を絵で表示します。全体像を人に説明したいときに便利です。追加インストールが必要な道具で、見るだけなので安全です。node_modules のような巨大フォルダを -I で除くと読みやすくなります。

```
tree -L 2 -I node_modules
```

| オプション | 意味 |
| --- | --- |
| `-L 2` | 深さ2段までに制限 |
| `-a` | 隠しファイルも表示 |
| `-d` | フォルダだけ表示 |
| `-I node_modules` | 指定した名前を除外 |
| `--gitignore` | .gitignore の設定に従って除外 |
| `-h` | ファイルの大きさを読みやすい単位で表示 |

### 🟢 `file`（ファイル）

**見るだけ・安全**

**一言でいうと**: そのファイルが何の種類なのかを判定して教えてくれる

拡張子ではなく中身を少し覗いて「これはPNG画像」「これはただの文章」と当てます。宅配便の箱を軽く振って中身を推測するようなものです。中身を書き換えることはありません。


## 変えるコマンド（要確認）

### 🟡 `mkdir`（メイク・ディレクトリ）

**変わるが戻せる**

**一言でいうと**: からっぽのフォルダを新しく作るだけの命令

フォルダ（ディレクトリ）を新しく作ります。机の上に空の書類ケースをひとつ置くようなもので、中身は何も入っていません。すでに同じ名前のフォルダがあると、エラーで止まるだけなので既存のものが壊れることはありません。まだ空なので、間違えたら rmdir で消せば完全に元通りになります。

```
mkdir docs/images
```

| オプション | 意味 |
| --- | --- |
| `-p` | 途中の親フォルダもまとめて作る。すでにあってもエラーにしない |
| `-v` | 作ったフォルダ名を1行ずつ表示する |
| `-m` | 作るときの権限（誰が読み書きできるか）を指定する |

### 🟡 `touch`（タッチ）

**変わるが戻せる**

**一言でいうと**: 空のファイルを作る、または日付だけ新しくする命令

ファイルが無ければ空のファイルを作り、すでにあれば「最後に触った日時」だけを今に書き換えます。本の中身は一切いじらず、貸出カードの日付だけ押し直すイメージです。中身は絶対に消えないので、既存ファイルに使っても安全です。新しく作ってしまった空ファイルは削除すれば元通りです。

```
touch README.md
```

| オプション | 意味 |
| --- | --- |
| `-c` | ファイルが無いときは新しく作らない |
| `-a` | 「読んだ日時」だけを変える |
| `-m` | 「変更した日時」だけを変える |
| `-r ファイル名` | 別のファイルと同じ日時にそろえる |
| `-d 日付` | 「2026-07-01」のように日付を文字で指定する |

### 🟡 `cp`（シーピー（コピー））

**変わるが戻せる**

**一言でいうと**: ファイルを複製する。行き先の同名ファイルは黙って上書き

元を残したまま写しを作ります。コピー機で紙を1枚コピーするのと同じで、原本はそのままです。ただし行き先に同じ名前のファイルがあると、何も聞かずに上書きし、上書きされた中身は戻せません。原本は無事なので「コピーしすぎた」だけなら消せば元通りですが、上書きが怖いときは -i を付けてください。

```
cp config.json config.json.bak
```

| オプション | 意味 |
| --- | --- |
| `-r / -R` | フォルダの中身ごとまるごとコピーする |
| `-i` | 上書きする前に「いい？」と1件ずつ聞く |
| `-n` | すでにある行き先は上書きせず飛ばす |
| `-p` | 日付や権限もそのまま引き継ぐ |
| `-a` | -dR --preserve=all と同じ。属性ごと丸写しにする |
| `-v` | 何をコピーしたか1行ずつ表示する |

### 🟡 `mv`（エムブイ（ムーブ））

**変わるが戻せる**

**一言でいうと**: ファイルの引っ越しと、名前の変更を兼ねる命令

ファイルを別の場所に移すか、名前を変えます。棚から別の棚へ本を移すだけで、コピーは残りません。行き先に同名ファイルがあると黙って上書きし、その中身は戻せません。移動そのものは、逆向きに mv すれば元の場所に戻せます。

```
mv draft.md articles/2026-07-25.md
```

| オプション | 意味 |
| --- | --- |
| `-i` | 上書きする前に確認する |
| `-n` | 同名があれば上書きしない |
| `-f` | 確認せず上書きする |
| `-b / --backup` | 上書きする前に、元ファイルの控えを残す |
| `-v` | 何を動かしたか表示する |

### 🔴 `rm`（アールエム（リムーブ））

**止めて確認**

**一言でいうと**: ファイルを消す命令。ゴミ箱を通らず、その場で消える

指定したファイルを削除します。パソコンの「ゴミ箱に入れる」とは違い、ゴミ箱を経由せずその場で消えるため、画面から元に戻す方法はありません。紙をシュレッダーにかけるのと同じで、原則として復旧できないと考えてください。Git で管理しているファイルなら git restore で復活できることもありますが、それ以外（.env、写真、ダウンロードしたファイルなど）は戻りません。

```
rm old-notes.txt
```

| オプション | 意味 |
| --- | --- |
| `-r / -R / --recursive` | フォルダとその中身を全部消す。1つではなく何百件も消える可能性があり、ここから危険度が跳ね上がる |
| `-f / --force` | 確認も警告も出さず、存在しないファイルでもエラーにしない。ブレーキを外す指定 |
| `-rf` | 「中身ごと」＋「無言で」の組み合わせ。最も事故が多い形。実行前に必ず消す場所のパスを声に出して確認する |
| `-i` | 1件ごとに確認する。唯一の安全側の指定 |
| `-d` | 空のフォルダだけ消す |
| `-v` | 消したものを1行ずつ表示する |
| `--no-preserve-root` | 通常は守られている「/（パソコン全体）」の保護を外す。絶対に使わない |

### 🟡 `rmdir`（リムーブ・ディレクトリ）

**変わるが戻せる**

**一言でいうと**: からっぽのフォルダだけを消す、安全側の削除命令

空のフォルダだけを削除します。中に何か入っていると「空ではない」とエラーになって止まるので、rm のように中身を巻き込む事故が起きません。中身のない箱をたたむようなもので、失うものはありません。間違えたら mkdir で作り直せば元通りです。

```
rmdir tmp
```

| オプション | 意味 |
| --- | --- |
| `-p` | 親フォルダまでさかのぼって、空なら順に消す |
| `--ignore-fail-on-non-empty` | 空でなくてもエラー表示を出さない |

### 🟡 `ln -s`（エルエヌ・エス（シンボリックリンク））

**変わるが戻せる**

**一言でいうと**: 別の場所への近道（ショートカット）を作る命令

実体はコピーせず、「本物はあちらにあります」という案内板だけを置きます。デスクトップのショートカットや、図書館の「この本は別の棚です」という案内カードと同じです。案内板を消してもリンク先の本体は無傷なので、作ったリンクは削除すれば元通りです。ただし -f を付けると、同じ名前の既存ファイルを消してリンクに置き換えるので注意してください。

```
ln -s ../shared/.env .env
```

| オプション | 意味 |
| --- | --- |
| `-s` | シンボリックリンク（ショートカット）を作る。普通はこれ |
| `-f` | 同名のものがあれば消して置き換える |
| `-n` | リンク先を追いかけず、リンクそのものを対象にする |
| `-r` | 相対パスでリンクを張る |
| `-v` | 作ったリンクを表示する |

### 🟡 `chmod`（チェンジ・モード）

**変わるが戻せる**

**一言でいうと**: ファイルを誰が読み書き実行できるかを切り替える命令

そのファイルを「読める・書ける・実行できる」のを誰に許すかを設定します。部屋のドアの鍵を、誰の鍵で開くように付け替えるかの指定です。数字（644 や 755）か記号（u+x など）で指定し、元の数字を指定し直せば権限は戻せます。ただし変更前の値を覚えていないと分からなくなるので、先に ls -l で今の状態を見ておくと安全です。

```
chmod +x scripts/deploy.sh
```

| オプション | 意味 |
| --- | --- |
| `-R` | フォルダの中身すべてにまとめて適用する。影響範囲が一気に広がる |
| `-v` | 変更したファイルを1行ずつ表示する |
| `--reference=ファイル` | 別のファイルと同じ権限にそろえる |
| `+x` | 実行できるようにする（スクリプトを動かすときによく使う） |
| `644` | 持ち主は読み書き、他の人は読むだけ |
| `755` | 持ち主は全部、他の人は読む＋実行だけ |
| `600` | 持ち主だけが読み書き。他の人は一切触れない |

### 🔴 `chmod 777`（チェンジ・モード・ナナナナナナ）

**止めて確認**

**一言でいうと**: 誰でも書き換えできる状態にする、穴を空ける設定

777 は「誰でも読める・書ける・実行できる」という、鍵を外して玄関を開け放つ設定です。動かないときの応急処置として提案されがちですが、他の人や別のプログラムに勝手に書き換えられる状態になります。数字を指定し直せば権限自体は戻せますが、その間に書き換えられた中身は戻りません。特に -R でフォルダごと 777 にするのは避け、本当に必要な権限だけを付けてください。

```
chmod -R 777 .   ← これは避ける
```

| オプション | 意味 |
| --- | --- |
| `-R` | 中身すべてに適用する。被害範囲が最大になる |

### 🔴 `chown`（チェンジ・オーナー）

**止めて確認**

**一言でいうと**: ファイルの持ち主を別の人に付け替える命令

ファイルの所有者とグループを変更します。本の見返しに書いてある名前を別の人に書き換えるようなもので、多くの場合 sudo（管理者権限）が必要です。持ち主を間違えると、自分のファイルなのに触れなくなることがあります。元の持ち主名が分かっていれば chown で戻せますが、-R で大量に変えると元の状態を復元しづらくなります。

```
sudo chown akimitu:staff config.json
```

| オプション | 意味 |
| --- | --- |
| `owner:group` | 持ち主とグループを同時に指定する |
| `:group` | グループだけを変える |
| `-R` | フォルダの中身すべての持ち主を変える |
| `-v` | 変更したファイルを表示する |

### 🔴 `sudo`（スードゥー）

**止めて確認**

**一言でいうと**: この1回だけ管理者として実行する、という宣言

後ろに続く命令を管理者（root）の権限で実行します。ビルの共用部を開けるマスターキーを借りるのと同じで、自分の部屋だけでなくパソコン全体に手が届いてしまいます。パスワードを一度入れると、既定では同じ画面で約5分間は再入力を求められません。sudo を付けた操作はパソコン全体に影響するので、元に戻す手順があるかを実行前に確認してください。

```
sudo systemctl restart nginx
```

| オプション | 意味 |
| --- | --- |
| `-u ユーザー名` | root ではなく、指定した人として実行する |
| `-i` | その人としてログインし直した状態の画面に入る |
| `-s` | シェル（コマンドを打つ画面）を管理者権限で起動する |
| `-k` | 覚えているパスワードを忘れさせる |
| `-v` | パスワードの有効時間を延ばす |

### 🟡 `kill`（キル）

**変わるが戻せる**

**一言でいうと**: 動いているプログラムに「終了して」と合図を送る命令

プロセス番号（PID）を指定して、そのプログラムに終了の合図を送ります。既定は TERM（15番）で、肩をたたいて「片付けて帰って」と伝えるのに近く、プログラム側が保存などの後片付けをしてから止まります。止めたプログラムは起動し直せますが、保存していなかった作業内容は戻りません。

```
kill 48213
```

| オプション | 意味 |
| --- | --- |
| `-15 / -TERM` | 既定。後片付けをさせてから止める |
| `-9 / -KILL` | 問答無用で止める。後片付けなし |
| `-l` | 使える合図の一覧を表示する |
| `-s 名前` | 合図を名前で指定する |

### 🔴 `kill -9`（キル・ナイン）

**止めて確認**

**一言でいうと**: 後片付けをさせず強制終了させる、最後の手段

KILL（9番）は、プログラム側が受け取って処理することができない合図なので、プログラムはその瞬間に消えます。書きかけの書類を保存させずにパソコンの電源を引き抜くのと同じで、作りかけのファイルやデータベースが壊れた形で残ることがあります。プロセスは起動し直せますが、壊れたデータは戻りません。まず kill（15番）を試し、それでも止まらないときだけ使ってください。

```
kill -9 48213
```

| オプション | 意味 |
| --- | --- |
| `-9 / -KILL` | 受け取り拒否できない強制終了。man ページも「後片付けの機会を与えない」と明記 |

### 🔴 `killall`（キルオール）

**止めて確認**

**一言でいうと**: 名前で指定して、当てはまるものを全部止める命令

番号ではなくプログラム名を指定し、その名前で動いているプロセスをまとめて止めます（既定は TERM）。「山田さんを呼んで」と言ったら社内の山田さん全員が来てしまうように、意図しないものまで巻き込みます。止めたものは起動し直せますが、保存前の作業は戻りません。実行前に -i で1つずつ確認するか、まず ps で対象を見ておくと安全です。

```
killall node
```

| オプション | 意味 |
| --- | --- |
| `-i` | 1つずつ確認してから止める |
| `-u ユーザー名` | その人のプロセスだけに限定する |
| `-e` | 名前が完全一致するものだけを対象にする |
| `-v` | 合図を送れたかどうかを報告する |
| `-9` | 強制終了させる |

### 🔴 `pkill`（ピーキル）

**止めて確認**

**一言でいうと**: 名前の一部でまとめて止める命令。killall の親戚

名前の一部が一致するプロセスに終了の合図（既定は TERM）を送ります。-f を付けると起動時のコマンド全文で探すので、当たる範囲がぐっと広くなります。名札が少し似ている人まで呼び出してしまう危険があるため、まず同じ条件で pgrep を実行して「誰が当たるか」を確認するのが定石です。止めたものは起動し直せますが、保存前の作業は戻りません。

```
pgrep -f "vite"  （まず誰が当たるか確認）
```

| オプション | 意味 |
| --- | --- |
| `-f` | コマンド全文で照合する。当たる範囲が広い |
| `-u ユーザー名` | 対象を特定の人に限定する |
| `-e` | 止めた名前と番号を表示する |
| `-i` | 大文字小文字を区別しない |
| `-9` | 強制終了させる |

### 🟡 `tar -czf（作る）`（ター・シーゼットエフ）

**変わるが戻せる**

**一言でいうと**: 複数のファイルを1つの圧縮ファイルにまとめる命令

指定したファイルやフォルダを1つの .tar.gz ファイルに詰めます。段ボール1箱に荷物をまとめて封をするイメージで、元のファイルはそのまま残ります。増えるだけなので、できた圧縮ファイルを削除すれば元通りです。ただし出力先に同じ名前のファイルがあると上書きされるため、名前だけは確認してください。

```
tar -czf backup.tar.gz articles/
```

| オプション | 意味 |
| --- | --- |
| `-c` | 新しく作る |
| `-z` | gzip で圧縮する（.tar.gz になる） |
| `-f ファイル名` | 作る圧縮ファイルの名前を指定する |
| `-v` | 詰めたファイル名を表示する |
| `-C フォルダ` | 先にそのフォルダへ移動してから処理する |

### 🟡 `tar -xzf（展開）`（ター・エックスゼットエフ）

**変わるが戻せる**

**一言でいうと**: 圧縮ファイルを開いて中身を取り出す命令

.tar.gz の中身を今いるフォルダに取り出します。段ボールを開けて中身を机に並べる作業です。同じ名前のファイルがあると確認なしで上書きされ、上書きされた中身は戻りません。まず -t で中身の一覧を見て、-C で取り出し先を指定するのが安全です。

```
tar -tzf backup.tar.gz   （まず中身を確認）
```

| オプション | 意味 |
| --- | --- |
| `-x` | 中身を取り出す |
| `-t` | 取り出さず、中身の一覧だけ見る（安全） |
| `-z` | gzip の圧縮を解く |
| `-f ファイル名` | 対象の圧縮ファイルを指定する |
| `-C フォルダ` | 指定したフォルダに取り出す |
| `-v` | 取り出したファイル名を表示する |

### 🟡 `zip`（ジップ）

**変わるが戻せる**

**一言でいうと**: Windows でもよく見る .zip 形式にまとめる命令

指定したファイルを .zip にまとめます。元のファイルは残るので、できた zip を消せば元通りです。すでにある zip を指定した場合は、中の同名ファイルが差し替わり、新しいものは追加されます（丸ごと作り直しではありません）。-d を付けると「zip の中から項目を削除する」動作に変わるので、意味が違うことに注意してください。

```
zip -r articles.zip articles/
```

| オプション | 意味 |
| --- | --- |
| `-r` | フォルダの中身も含めてまとめる |
| `-e` | パスワードを付ける（入力は画面に出ない） |
| `-q` | メッセージを出さない |
| `-d` | zip の中から指定した項目を削除する（作る指定ではない） |

### 🟡 `unzip`（アンジップ）

**変わるが戻せる**

**一言でいうと**: .zip を開いて中身を取り出す命令

zip の中身を取り出します。既定では同名ファイルがあるときに「上書きする？」と1つずつ聞いてくれるので、黙って壊れることはありません。-o を付けるとその確認を飛ばして全部上書きし、上書きされた中身は戻りません（man ページ自身が「危険な指定」と書いています）。-l で先に中身の一覧を見て、-d で取り出し先を指定するのが安全です。

```
unzip -l archive.zip
```

| オプション | 意味 |
| --- | --- |
| `-l` | 中身の一覧だけ表示する（取り出さない） |
| `-d フォルダ` | 指定したフォルダに取り出す |
| `-o` | 確認せず全部上書きする。man ページが「危険」と明記 |
| `-q` | メッセージを減らす |

### 🔴 `sed -i`（セド・アイ（イン・プレース））

**止めて確認**

**一言でいうと**: ファイルの中身を一括で置き換え、その場で保存する

「この文字をこの文字に置き換える」をファイル全体に一括適用し、結果を元のファイルに直接書き戻します。原稿にペンで直接上書きするようなもので、-i だけだと控えが残らず、置換前の中身は戻せません。-i.bak のように拡張子を付けると元ファイルの控えができ、そこから戻せます。Git で管理しているファイルなら git diff で変更を確認し、git restore で戻せます。

```
sed -i.bak 's/旧サービス名/新サービス名/g' README.md
```

| オプション | 意味 |
| --- | --- |
| `-i` | その場で書き換える。控えは残らない |
| `-i.bak` | 書き換える前に .bak という控えを作ってから書き換える（推奨） |
| `s/old/new/` | 1行の中の最初の1件だけ置き換える |
| `s/old/new/g` | 1行の中の全部を置き換える（g = global） |
| `-n` | 自動表示をやめる。-i と一緒に使うと中身が空になる事故が起きる |

### 🟡 `tee`（ティー）

**変わるが戻せる**

**一言でいうと**: 画面に出しながら、同じ内容をファイルにも書く命令

パイプで受け取った内容を画面に表示しつつ、ファイルにも保存します。コピー機で「1枚は手元、1枚は書類棚へ」と分ける動きで、T字路（tee）が名前の由来です。既定では指定したファイルを上書きするため、元の中身は戻りません。-a を付けると末尾に追記になるので、既存の設定ファイルに足すときは必ず -a を使ってください。

```
npm run build | tee build.log
```

| オプション | 意味 |
| --- | --- |
| `-a` | 上書きせず、末尾に追記する |

| `stop` | 今すぐ停止する |
| `restart` | 止めてから起動する（設定変更の反映に使う） |
| `status` | 今の状態と直近のログを表示する（読むだけで安全） |

### 🔴 `systemctl enable / disable`（システムシーティーエル・イネーブル）

**止めて確認**

**一言でいうと**: マシン起動時に自動で立ち上げるかを切り替える命令

enable は「次回のマシン起動時に自動で立ち上がる」状態にする設定で、今すぐ起動はしません。disable はその自動起動をやめます。ブレーカーを入れておくかどうかの設定に近く、今の動作ではなく次回以降に効きます。逆の命令を実行すれば元に戻せますが、disable したまま再起動するとサービスが上がらないので注意してください。

```
sudo systemctl enable nginx
```

| オプション | 意味 |
| --- | --- |
| `enable` | 起動時に自動で立ち上がる設定にする（今は起動しない） |
| `disable` | 自動起動をやめる |

### 🔴 `sudo apt install`（スードゥー・アプト・インストール）

**止めて確認**

**一言でいうと**: Ubuntu などでソフトを入れる命令（管理者権限が必要）

Debian／Ubuntu 系 Linux でソフトを導入します。パソコン全体にインストールするため sudo が必要で、共用の棚に道具を追加する操作です。apt remove で外せるので基本は元に戻せますが、依存関係で他のソフトも一緒に入れ替わることがあります。先に sudo apt update で入手先の一覧を新しくしてから install するのが一般的です。

```
sudo apt update && sudo apt install jq
```

| オプション | 意味 |
| --- | --- |
| `install` | 入れる |
| `remove` | 消す（設定ファイルは残る） |
| `update` | パッケージ情報の一覧を更新するだけ。ソフト自体は変わらない |
| `upgrade` | 入っているソフトを新しい版に更新する |
| `autoremove` | 依存関係で入り、もう不要になったものを削除する |

### 🟡 `/dev/null`（デブ・ヌル）

**変わるが戻せる**

**一言でいうと**: 書き込んだ内容がそのまま捨てられる、専用のゴミ箱

ここに送ったデータは保存されず、そのまま消えます。シュレッダー直結の投入口のようなもので、2>/dev/null と書くとエラー表示だけを黙らせられます。ファイルを壊す記号ではありませんが、捨てた内容は取り戻せません。原因を調べている最中にエラーを捨ててしまうと、問題が見えなくなるので注意してください。

```
npm run build 2>/dev/null
```
