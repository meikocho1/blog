画面に `● Read(...)` のように出てくるツール名、許可を求める画面の選択肢、権限モードの一覧です。

**「今なにをしたのか」を読み取るための章です。** 読み方の考え方そのものは第9章で扱います。

:::message
**この章は「引く」ためのものです。頭から読む必要はありません。**

記号の意味: 🟢 見るだけ（安全） / 🟡 変わるが戻せる / 🔴 止めて確認 / 📖 用語
:::

### 🟢 `Read`（リード）

**見るだけ・安全**

**一言でいうと**: ファイルの中身を読むだけ。何も書き換えない

Claude があなたのパソコンのファイルを開いて中身を見た、という表示です。図書館で本を棚から取って読むだけで、本には書き込まない状態と同じです。何も変わらないので、ふつうは許可を聞かれずに実行されます。ただし今作業しているフォルダの外にあるファイルを読むときは確認が出ます。

```
● Read(package.json)
  ⎿  Read 42 lines
```

### 🔴 `Write`（ライト）

**止めて確認**

**一言でいうと**: ファイルを新しく作る、または丸ごと上書きする

まっさらなノートを一冊用意するか、すでに書いてあるノートのページを全部消して書き直す動作です。既にあるファイルに使われた場合、元の中身は残りません。だから実行前に必ず確認が出ます。「そのファイル、もう中身があるのでは？」と一度立ち止まってください。

```
● Write(README.md)
```

### 🟡 `Edit`（エディット）

**変わるが戻せる**

**一言でいうと**: ファイルの中の一部分だけを書き換える

手紙全体を書き直すのではなく、間違った一文だけを修正液で直すイメージです。変更前と変更後が色分けで並んで表示され、そこで許可を求められます。画面では Update(ファイル名) と表示されることもあります。Git で管理していれば元に戻せるので、Write よりは気楽です。

```
● Update(src/app.ts)
  ⎿  Updated with 3 additions and 1 removal
```

### 🔴 `Bash`（バッシュ）

**止めて確認**

**一言でいうと**: 黒い画面の命令文を Claude が代わりに打って実行する

何でも回せる万能ドライバーのようなもので、ファイルを消すことも外部に送ることもできます。読むだけの安全な命令（ls や git status など）は確認なしで動きますが、それ以外は必ず確認が出ます。表示された命令文の中に rm（消す）や push（外に出す）が入っていないか、目で確認してから許可してください。

```
● Bash(npm run build)
  ⎿  Build succeeded
```

### 🔴 `PowerShell`（パワーシェル）

**止めて確認**

**一言でいうと**: Windows 用の命令文を Claude が実行する

Bash の Windows 版にあたるものです。やれることの幅広さも危なさも Bash と同じで、ファイルを消すことも外に送ることもできます。Windows で使っているときだけ画面に出ます。中身を読まずに許可しないでください。

```
● PowerShell(Get-ChildItem)
```

### 🟢 `Glob`（グロブ）

**見るだけ・安全**

**一言でいうと**: ファイル名のパターンで、該当する場所を探し出す

「.md で終わるファイルを全部出して」のように、名前の形だけで探す動作です。本棚の背表紙のタイトルだけを見て該当する本を拾い出すのと同じで、中身は読みません。何も変わらないので確認は出ません。

```
● Glob(**/*.md)
  ⎿  Found 12 files
```

### 🟢 `Grep`（グレップ）

**見るだけ・安全**

**一言でいうと**: ファイルの中身を全文検索して、該当する行を探す

本を全部めくって「この単語が書いてあるページ」を付箋で拾い出す動作です。Glob が背表紙で探すのに対して、Grep は中身で探します。読むだけなので何も変わらず、確認も出ません。

```
● Grep(pattern: "TODO")
  ⎿  Found 5 matches
```

### 🟡 `NotebookEdit`（ノートブックエディット）

**変わるが戻せる**

**一言でいうと**: Jupyter ノートブックのマス目（セル）を書き換える

データ分析で使う .ipynb というファイルは、文章と計算式が「マス目」ごとに区切られた特殊なノートです。その一マスだけを書き換える動作がこれです。ファイルが変わるので確認が出ます。

```
● NotebookEdit(analysis.ipynb)
```

### 🔴 `WebFetch`（ウェブフェッチ）

**止めて確認**

**一言でいうと**: 指定した URL のページを取ってきて読む

ネットの住所を渡して、そのページを読んでもらう動作です。外の世界に「このページください」と話しかけるので、あなたの環境から外へ通信が出ていきます。URL の中に社内情報や顧客名が混ざっていると、それが外に出ます。必ず確認が出るので、行き先のドメインを見てください。

```
● WebFetch(https://code.claude.com/docs/en/tools-reference)
```

### 🔴 `WebSearch`（ウェブサーチ）

**止めて確認**

**一言でいうと**: ネットで検索して、結果の一覧を持ってくる

検索窓に言葉を入れて調べるのと同じ動作です。ただし検索した言葉そのものが外部の検索サービスに送られます。社内の固有名詞や顧客のお名前を含む検索は避けてください。会議室の会話を外の窓を開けたまま話すようなものです。

```
● WebSearch("Next.js 16 cache components")
```

### 🟡 `Agent`（エージェント）

**変わるが戻せる**

**一言でいうと**: 別の Claude を子分として呼び、結果だけ受け取る

記憶を分けた別の Claude を立ち上げて、調べ物などを丸ごと任せる仕組みです。下請けに仕事を出して報告書だけ受け取るイメージで、途中のやりとりはあなたには見えません。画面では Task と表示されることもあります。呼び出し自体には確認は出ませんが、子分がファイルを変えようとしたときはあなたに確認が来ます。

```
● Task(コードベースを調査)
  ⎿  Done (18 tool uses)
```

### 🟡 `Skill`（スキル）

**変わるが戻せる**

**一言でいうと**: あらかじめ用意した手順書を呼び出して進める

「デプロイのやり方」「レビューのチェック項目」などをまとめた手順書のことです。引き出しからレシピカードを出して、その通りに料理を進めるイメージです。手順書の中で他の道具も使うので、実行時に確認が出ます。

```
● Skill(code-review)
```

### 🟢 `TaskCreate / TaskList / TaskUpdate`（タスククリエイト / タスクリスト / タスクアップデート）

**見るだけ・安全**

**一言でいうと**: 作業のやることリストを作る・見る・進捗を更新する

Claude が「今日やること」のメモを自分で書いて、終わったら線を引いていく仕組みです。冷蔵庫に貼る買い物リストと同じで、あなたのファイルには何も起きません。Ctrl+T を押すとこのリストを画面で開けます。

```
● TaskCreate(テストを追加する)
```

### 🟢 `TodoWrite`（トゥドゥーライト）

**見るだけ・安全**

**一言でいうと**: 旧式のやることリスト機能。今は既定でオフ

以前は Claude のやることリストがこの名前で表示されていました。バージョン 2.1.142 以降は既定で無効になり、TaskCreate などの新しい仕組みに置き換わっています。古い記事に出てくる名前なので、見かけても「今のリスト機能の昔の呼び名」と思って大丈夫です。

```
● TodoWrite(3 items)
```

### 🟢 `AskUserQuestion`（アスクユーザークエスチョン）

**見るだけ・安全**

**一言でいうと**: 選択肢を出して、あなたに決めてもらう質問

Claude が迷ったときに「A案とB案、どちらにしますか」と選択肢の形で聞いてくる仕組みです。レストランで「ライスかパンどちらに」と聞かれるのと同じで、答えるまで待っています。矢印キーで選ぶか、自分で文章を打って答えられます。

```
どちらの方針で進めますか？
  1. 既存の関数を修正する
  2. 新しく関数を作る
  3. Other（自分で書く）
```

### 🟢 `EnterPlanMode / ExitPlanMode`（エンタープランモード / エグジットプランモード）

**見るだけ・安全**

**一言でいうと**: 計画モードに入る、計画を出して承認をもらう

作る前に「こう進めます」という設計図を書くモードへの出入りです。大工さんが木を切る前に図面を見せてくれる、あの一手間にあたります。ExitPlanMode が呼ばれると計画が画面に出て、進めてよいか聞かれます。

```
● ExitPlanMode
  ⎿  計画を確認してください
```

### 🟢 `LSP`（エルエスピー）

**見るだけ・安全**

**一言でいうと**: 「この関数どこで定義？」をプログラムに聞く道具

コードの意味を理解しているソフトに、定義の場所や型の間違いを問い合わせる動作です。辞書の索引を引いて「この言葉はここに載っている」と教えてもらうのと同じです。読むだけなので何も変わりません。

```
● LSP(definition: handleSubmit)
```

### 🔴 `Monitor`（モニター）

**止めて確認**

**一言でいうと**: 命令を裏で動かし続け、出てくる行を逐一見張る

サーバーのログを流し続けて、変化があったら Claude が気づく仕組みです。やかんを火にかけたまま横で見ていて、沸いたら反応するイメージ。裏で命令文を実行し続けるので、Bash と同じ危なさがあります。必ず確認が出ます。

```
● Monitor(npm run dev)
```

### 🟡 `EnterWorktree / ExitWorktree`（エンターワークツリー / エグジットワークツリー）

**変わるが戻せる**

**一言でいうと**: 作業用の別部屋を作って、そこで作業する／戻る

今のフォルダをそのまま残したまま、同じ内容の「作業用コピー部屋」を隣に作る Git の機能です。本番の机を汚さずに、同じ書類のコピーを別の机で試すイメージ。新しいフォルダができるので確認が出ます。

```
● EnterWorktree(feature/login)
```

### 🔴 `Artifact`（アーティファクト）

**止めて確認**

**一言でいうと**: 作った資料を claude.ai 上のページとして公開する

HTML や Markdown のファイルを、ブラウザで見られるページとして claude.ai に上げる動作です。最初は自分だけが見られる状態ですが、リンクを渡せば他の人も見られます。つまり中身が自分のパソコンの外に出ます。顧客情報や社外秘が混ざっていないか必ず確認してください。

```
● Artifact(report.html)
  ⎿  https://claude.ai/artifact/...
```

### 🔴 `SendUserFile`（センドユーザーファイル）

**止めて確認**

**一言でいうと**: 作ったファイルをあなたの手元に送り届ける

生成した図やレポートを、会話の中で受け取れる形で送ってくる動作です。宅配便で成果物が届くイメージ。ファイルの中身がやりとりに乗るので、社外秘が混ざっていないか確認してください。

```
● SendUserFile(diagram.png)
```

### 🟢 `ToolSearch`（ツールサーチ）

**見るだけ・安全**

**一言でいうと**: 必要になった道具を、その場で探して読み込む

使える道具が多すぎるとき、最初は名前だけ持っておいて、必要になったら説明書を取り出す仕組みです。工具箱を全部広げず、使う工具だけ取り出すのと同じ。何も変わりません。

```
● ToolSearch("select:WebSearch,WebFetch")
```

### 🟡 `mcp__サーバー名__ツール名`（エムシーピー）

**変わるが戻せる**

**一言でいうと**: 外部サービスから借りてきた道具の名前の形

Slack や Google Drive などの外部サービスを Claude につないだとき、その道具はこの形の名前で画面に出ます。mcp__ で始まっていたら「Claude 本体ではなく、外からつないだ道具」という合図です。外のサービスとやりとりするので、何を送るのか気にしてください。

```
● mcp__Google_Drive__search_files(...)
```

### 🟡 `MCP server`（エムシーピーサーバー）

**変わるが戻せる**

**一言でいうと**: Claude に外部サービスをつなぐ差し込み口

Slack、データベース、Figma などを Claude から直接触れるようにする接続の仕組みです。テレビにゲーム機をつなぐ HDMI 端子のようなもので、つなぐと使える道具が増えます。/mcp と打つと、つながっている一覧と状態（接続済み・認証が必要・not configured）が見られます。

```
/mcp
  github        connected (24 tools)
  notion        needs authentication
```

### 🟡 `Hook`（フック）

**変わるが戻せる**

**一言でいうと**: 決めた場面で自動的に動く、仕掛けておいた処理

「ファイルを保存したら必ず整形する」のように、特定の場面で自動実行される仕掛けです。玄関のセンサーライトと同じで、条件を満たすと勝手に点きます。Claude の判断ではなく設定ファイルで動くため、意図しない処理が仕込まれていないか確認する価値があります。

```
PostToolUse hook: prettier --write
```

### 🟡 `Subagent`（サブエージェント）

**変わるが戻せる**

**一言でいうと**: 別の記憶で並行して働く、Claude の分身

Agent ツールで呼び出される「子分の Claude」のことです。会話の記憶を分けているので、長い調べ物を任せても本体の会話が散らかりません。既定では裏で動き、必要なときは本体の会話であなたに許可を聞いてきます。Ctrl+X Ctrl+K を2回押すと全部止められます。

```
● Task(code-reviewer)
  ⎿  Running in background…
```

### 🟡 `許可プロンプト（編集の3択）`（きょかプロンプト）

**変わるが戻せる**

**一言でいうと**: ファイル変更前に出る、はい・いつでもはい・いいえ

Claude が編集しようとすると、変更前と変更後が並んで表示され、3つの選択肢が出ます。「Yes」はこの一件だけ許可、「Yes, and don't ask again for edits」はこのセッション中の編集を全部自動で許可、「No」は断って理由を伝えます。判子を1回だけ押すか、今日の分は全部任せるか、断るかの三択です。迷ったら No にして質問してください。

```
Do you want to make this edit to app.ts?
  1. Yes
  2. Yes, and don't ask again for edits
  3. No
```

### 🔴 `Yes, don't ask again`（イエス ドントアスクアゲイン）

**止めて確認**

**一言でいうと**: 同じ命令を今後ずっと確認なしで許可する設定

Bash の命令に対してこれを選ぶと、その許可がリポジトリの .claude/settings.local.json に保存され、次回以降のセッションでも確認なしで動くようになります。合鍵を渡すのと同じで、一度渡したら意識しないまま使われ続けます。ファイル編集の許可はセッション終了までですが、こちらは恒久です。npm test のような無害な命令に限って使ってください。

```
Do you want to run npm test?
  1. Yes
  2. Yes, don't ask again
  3. No
```

### 🟡 `計画の承認（4択）`（けいかくのしょうにん）

**変わるが戻せる**

**一言でいうと**: 計画モードの終わりに出る、進め方の選択肢

計画ができると「どう進めますか」と聞かれます。「Yes, and use auto mode」（または Yes, auto-accept edits）は許可を聞かずに一気に進める道、「Yes, manually approve edits」は1件ずつ確認しながら進める道、「No, keep planning」は計画のまま直しを指示する道です。工事の見積書に「このまま任せる」「一工程ずつ確認する」「まだ相談したい」の三択で答えるイメージ。慣れないうちは manually approve が安心です。

```
Ready to code?
  1. Yes, and use auto mode
  2. Yes, manually approve edits
  3. No, keep planning
```

### 🟡 `フォルダ信頼ダイアログ`（フォルダしんらいダイアログ）

**変わるが戻せる**

**一言でいうと**: このフォルダの設定を信じるか、最初に聞かれる確認

新しいプロジェクトを開いたとき、そのフォルダに入っている許可設定を有効にしてよいか聞かれます。「Yes, I trust this folder」で有効になり、「No, continue without these permissions」だと設定を無視して作業します。よく知らない人からもらったフォルダには、勝手に許可を広げる設定が入っていることがあるので、中身に心当たりがないなら No が安全です。

```
Do you trust the files in this folder?
  1. Yes, I trust this folder
  2. No, continue without these permissions
```

### 📖 `default（Manual）モード`（デフォルト / マニュアル）

**一言でいうと**: 読む以外は毎回確認してくる、標準の慎重モード

何かを変える動作のたびに必ず許可を聞いてくる、初期設定の状態です。設定ファイル上の名前は default ですが、画面上の表示は Manual です。助手席から一つずつ「曲がっていい？」と聞かれる運転のようなもので、遅いけれど事故りません。慣れるまではこのままで十分です。

```
⏸ manual mode on
```

### 🟡 `acceptEdits`（アクセプトエディッツ）

**変わるが戻せる**

**一言でいうと**: ファイル編集を確認なしで自動的に受け入れるモード

読み込みとファイル編集、それに mkdir や cp のような一般的なファイル操作を、確認なしで進めるモードです。原稿の赤入れを毎回見せてもらうのをやめて、あとでまとめて読む状態にあたります。自分でレビューする前提のときに便利ですが、気づかないうちに複数のファイルが変わります。

```
⏵⏵ accept edits on
```

### 📖 `plan モード`（プラン）

**一言でいうと**: 作らずに調べて、進め方の設計図だけ書くモード

Claude が読んで調べて計画を書くだけで、あなたのファイルには手を出さないモードです。家を建てる前に図面と見積を出す段階にあたります。Shift+Tab で切り替えるか、質問の頭に /plan を付けても入れます。作業内容の大きさを把握したいときに、まずここから始めるのが安全です。

```
⏸ plan mode on
```

### 🟡 `auto モード`（オート）

**変わるが戻せる**

**一言でいうと**: 別のAIが安全性を審査しつつ、確認をほぼ省くモード

許可プロンプトを出さずに進めますが、実行前に別の判定用モデルが「頼まれた範囲を超えていないか」を審査します。ノーチェックではなく、門番が立っている自動ドアのイメージです。curl でダウンロードしたものをそのまま実行する、外部に機密を送る、本番へのデプロイなどは既定で止まります。それでも安全の保証ではないので、大事な作業では使わないでください。

```
⏵⏵ auto mode on
```

### 🟡 `dontAsk モード`（ドントアスク）

**変わるが戻せる**

**一言でいうと**: 事前に許した道具しか使えない、締めたモード

確認を出さない代わりに、あらかじめ許可リストに書いた道具しか使えません。許可されていないことは黙って諦めます。入館証を持っている人しか通れないゲートのようなもので、自動処理やスクリプト向けです。Shift+Tab の切り替えには出てこず、起動時の指定だけで入ります。

```
⏵⏵ don't ask on
```

### 🔴 `bypassPermissions`（バイパスパーミッションズ）

**止めて確認**

**一言でいうと**: すべての確認を飛ばす。安全装置を全部外した状態

何を聞かれることもなく、ファイルの削除も外部への送信もそのまま実行されます。車のブレーキとシートベルトを外して走るのと同じで、公式ドキュメントも「隔離されたコンテナや仮想マシンのみ」と書いています。あなたのお仕事のパソコンで使うものではありません。この表示が出ていたら、まず抜けてください。

```
⏵⏵ bypass permissions on
```

### 🔴 `--dangerously-skip-permissions`（デンジャラスリー スキップ パーミッションズ）

**止めて確認**

**一言でいうと**: 起動時に安全装置を外す指定。名前の通り危険

claude を起動するときにこれを付けると、bypassPermissions で始まります。オプション名に自ら「dangerously（危険なやり方で）」と書いてあるのが答えです。ネット記事で「これを付けると快適」と紹介されていても、業務のパソコンでは付けないでください。

```
claude --dangerously-skip-permissions
```

| オプション | 意味 |
| --- | --- |
| `--permission-mode plan` | 計画モードで起動する（安全な使い方） |
| `--allow-dangerously-skip-permissions` | 切り替え候補に入れるだけで、すぐには有効にしない |

### 📖 `Shift+Tab`（シフト タブ）

**一言でいうと**: どこまで自分で確認するかを切り替えるキー

押すたびに Manual → accept edits → plan と順に切り替わります。車のギアを入れ替えるようなもので、今どこにいるかは入力欄の下のバッジで分かります。⏸ が付いているときは慎重な側、⏵⏵ が付いているときは自動で進む側です。

```
⏸ plan mode on / ⏵⏵ accept edits on
```

### 📖 `Extended thinking（Option+T）`（エクステンデッド シンキング）

**一言でいうと**: 答える前に長く考えさせる設定。難問向け

すぐ答えるのではなく、内部で筋道を立ててから答えるようにする切り替えです。暗算で即答するか、紙に書いて計算するかの違いにあたります。macOS は Option+T、Windows / Linux は Alt+T で入り切りできます。時間はかかりますが、複雑な設計や原因不明の不具合では当たる率が上がります。

```
Option+T（macOS）/ Alt+T（Windows・Linux）
```

### 🟢 `Esc`（エスケープ）

**見るだけ・安全**

**一言でいうと**: 今の作業を止める、または画面を閉じるキー

Claude が長く動いていて「それは違う」と思ったら、まず Esc です。走っている作業がその場で止まり、ダイアログが出ているときはそれを閉じます。エレベーターの扉を押さえるボタンのように、いつでも押していい安全なキーです。2回続けて押すと入力の下書きを消したり、会話を巻き戻したりできます。

```
esc to interrupt
```

### 🟢 `Ctrl+O`（コントロール オー）

**見るだけ・安全**

**一言でいうと**: やりとりの全文記録を開いて見返すキー

画面に短くまとめられている部分も含めて、会話とツールの実行記録を full 表示で読めます。議事録を後ろから読み直すイメージ。読むだけなので、何が起きたか分からなくなったときに気軽に押してください。もう一度押すと元に戻ります。

```
Ctrl+O（transcript viewer）
```

### 🟢 `Ctrl+T`（コントロール ティー）

**見るだけ・安全**

**一言でいうと**: Claude のやることリストを開いて進捗を見るキー

今どこまで進んで、あと何が残っているかの一覧が出ます。長い作業のときに「今どのあたり？」を確かめる用途です。読むだけなので安全です。

```
Ctrl+T（task checklist）
```
