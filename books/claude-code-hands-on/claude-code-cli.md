Claude Code を動かすためのコマンドと、会話中に打てる `/` から始まるコマンド（スラッシュコマンド）の一覧です。

**ここは Claude Code を操作する側のコマンドで、AI が実行して見せる Linux コマンドとは別物です。**
AI が実行するコマンドは第4章以降を見てください。

**この章は「引く」ためのものです。頭から読む必要はありません。**

記号の意味: 🟢 見るだけ（安全） / 🟡 変わるが戻せる / 🔴 止めて確認 / 📖 用語
:::

## 起動コマンドとオプション

### 🟢 `claude`（クロード）

**見るだけ・安全**

**一言でいうと**: Claude Code を起動する合図。これを打つと会話が始まる

ターミナル（黒い画面）で claude と打ってEnterを押すと、Claude Code が立ち上がって話しかけられる状態になります。お店のドアを開けて「こんにちは」と入っていくのと同じで、これが入口です。今いるフォルダが作業場所として自動で選ばれるので、触ってほしいフォルダに移動してから打つのがコツです。claude "この企画書を直して" のように、最初の頼み事を一緒に書いてしまうこともできます。

```
claude
```

| オプション | 意味 |
| --- | --- |
| `-p` | 返事を1回だけ表示して終了する |
| `-c` | 直前の会話の続きから始める |
| `-v` | バージョン番号だけ表示する |

### 🟢 `claude "質問"`（クロード）

**見るだけ・安全**

**一言でいうと**: 起動と同時に最初の用件を伝える書き方

claude の後ろにダブルクォート（"）で囲んで用件を書くと、起動してすぐその話から始まります。電話をかけて「もしもし」を飛ばして本題から入るようなものです。日本語でそのまま書いて大丈夫です。

```
claude "このフォルダが何のプロジェクトか教えて"
```

### 🟢 `claude -p`（クロード ピー）

**見るだけ・安全**

**一言でいうと**: 聞いて答えをもらってすぐ終わる、使い捨てモード

-p は print（表示）の頭文字で、答えを画面に出したらそのまま終了します。会話を続けずに一問一答したいときに使います。自動販売機に小銭を入れて品物が出てきたら終わり、というイメージです。他のコマンドの結果を渡して読ませることもできます。

```
claude -p "この関数は何をしている？"
```

| オプション | 意味 |
| --- | --- |
| `--output-format json` | 答えを機械が読みやすい形で出す |
| `--max-turns 3` | 作業の往復回数に上限をつける |

### 🟢 `claude --continue`（クロード コンティニュー）

**見るだけ・安全**

**一言でいうと**: 同じフォルダの一番新しい会話を、そのまま再開する

-c と略せます。前回そのフォルダで話していた内容を覚えたまま続きから始まります。読みかけの本にしおりを挟んでおいて、次の日そのページから読み直すのと同じです。うっかりウィンドウを閉じてしまった後の復帰に一番よく使います。

```
claude -c
```

| オプション | 意味 |
| --- | --- |
| `-c` | --continue の短い書き方 |

### 🟢 `claude --resume`（クロード レジューム）

**見るだけ・安全**

**一言でいうと**: 過去の会話を一覧から選んで再開する

-r と略せます。--continue が「一番新しいものを自動で」なのに対し、こちらは過去の会話が一覧で出てきて、どれに戻るかを自分で選べます。録画した番組の一覧から見たい回を選ぶ感覚です。会話に名前を付けておくと、その名前で直接指定できます。

```
claude -r
```

| オプション | 意味 |
| --- | --- |
| `-r` | --resume の短い書き方 |
| `--fork-session` | 元の会話を残したまま枝分かれさせる |

### 🟢 `--model`（モデル）

**見るだけ・安全**

**一言でいうと**: どの頭脳（AIの種類）で作業させるかを指定する

Claude には得意分野と速さの違う複数の種類があり、これで選びます。じっくり考える人と手早くこなす人のどちらに頼むかを決めるのに近いです。opus、sonnet、haiku のような呼び名で指定します。指定しなければ、いつも使っている設定のものが選ばれます。

```
claude --model sonnet
```

### 🟢 `--effort`（エフォート）

**見るだけ・安全**

**一言でいうと**: どれくらい念入りに考えさせるかの目盛り

low / medium / high / xhigh / max などを指定して、考える深さを変えられます。低いほど速くて安く、高いほど時間とお金がかかる代わりに丁寧です。料理を「時短で」か「じっくり煮込んで」かを頼むときの違いに似ています。会話中は /effort でも変えられます。

```
claude --effort high
```

### 🟡 `--add-dir`（アドディレクトリ）

**変わるが戻せる**

**一言でいうと**: 作業してよいフォルダを追加で許可する

Claude は原則として起動したフォルダの中だけを見ます。これを付けると、別のフォルダも読み書きできるようになります。家の中で「この部屋も入っていいですよ」と鍵を渡すのと同じなので、渡す範囲は必要な分だけにしてください。会話中は /add-dir でも追加できます。

```
claude --add-dir ../共有素材
```

### 🟡 `--permission-mode`（パーミッションモード）

**変わるが戻せる**

**一言でいうと**: 確認をどれくらい取るかの構えを最初から決める

default（Manual、毎回聞く）、acceptEdits（ファイル書き換えは黙って進める）、plan（まず計画だけ立てて手は出さない）などを起動時に選べます。新人に「一つずつ確認してね」と言うか「任せるよ」と言うかの違いです。会話中は Shift+Tab で切り替えられます。

```
claude --permission-mode plan
```

### 🔴 `--dangerously-skip-permissions`（デンジャラスリー スキップ パーミッションズ）

**止めて確認**

**一言でいうと**: 全部の確認を飛ばす。事故が起きても止まらない

名前に dangerously（危険なことに）と入っている通り、ファイルの削除や外部への送信も一切確認せず実行されます。ブレーキを外した自転車で坂を下るようなもので、公式にも「隔離された環境でだけ」と書かれています。会社のパソコンや本番のデータがある場所では絶対に使わないでください。使いたい場面が出てきたら、まず人に相談してください。

```
claude --dangerously-skip-permissions
```

### 🟢 `--verbose`（バーボース）

**見るだけ・安全**

**一言でいうと**: 裏で何をしているかを細かく画面に出す

通常は省略される内部のやりとりまで表示されます。うまく動かないときの原因探しに使います。料理の完成品だけでなく調理の手順まで全部見せてもらう感じです。見るだけなので安全です。

```
claude --verbose
```

### 🟢 `--debug`（デバッグ）

**見るだけ・安全**

**一言でいうと**: 不具合調査用に、通信やエラーの記録まで表示する

--verbose よりさらに詳しく、通信やMCP接続の内部記録まで出します。カテゴリを指定して絞ることもできます。車の調子が悪いときに整備士が診断機をつなぐのと同じで、原因を人に伝えるための材料集めです。

```
claude --debug "api,mcp"
```

| オプション | 意味 |
| --- | --- |
| `--debug-file <path>` | 記録を指定したファイルに書き出す |

### 🟢 `--version`（バージョン）

**見るだけ・安全**

**一言でいうと**: 今入っている Claude Code の版番号を表示するだけ

-v と略せます。「今どの版を使っているか」を確認します。不具合を報告するときや、公式ドキュメントに「v2.1.200以降で使えます」と書かれた機能を試す前に確認します。持っているアプリの版数を設定画面で見るのと同じことです。

```
claude --version
```

| オプション | 意味 |
| --- | --- |
| `-v` | --version の短い書き方 |

### 🟡 `claude update`（クロード アップデート）

**変わるが戻せる**

**一言でいうと**: Claude Code 本体を最新版に入れ替える

新しい版が出ていれば入れ替えます。スマホのアプリを更新するのと同じで、たいてい良くなりますが、まれに動きや画面が変わって戸惑うことがあります。締め切り直前ではなく、余裕のあるときにやるのが無難です。

```
claude update
```

### 🟢 `claude doctor`（クロード ドクター）

**見るだけ・安全**

**一言でいうと**: 入っている状態がおかしくないかを健康診断する

インストールの重複、PATH（コマンドの置き場所）の問題、設定ファイルの書き間違いなどを調べて報告します。読むだけで勝手に直さないので安心して打てます。人間の健康診断と同じで、結果を持って相談すると話が早くなります。会話中は /doctor でも同じことができます。

```
claude doctor
```

### 🟡 `claude auth login`（クロード オース ログイン）

**変わるが戻せる**

**一言でいうと**: 自分の Anthropic アカウントでログインする

Claude Code を使う権利を紐づける手続きです。ブラウザが開いて、そこで承認します。動画配信サービスに初回だけログインするのと同じで、一度済ませればしばらく打つ必要はありません。会話中は /login でも同じです。

```
claude auth login
```

### 🟡 `claude auth logout`（クロード オース ログアウト）

**変わるが戻せる**

**一言でいうと**: ログイン状態を解除する。共有端末で使う

保存されているログイン情報を消します。人に貸すパソコンや共用端末で作業した後に打ちます。ネットカフェを出るときにログアウトするのと同じ習慣です。次に使うときは再度ログインが必要になります。

```
claude auth logout
```

### 🔴 `claude setup-token`（クロード セットアップ トークン）

**止めて確認**

**一言でいうと**: 長期間有効な合鍵を作る。漏れると重大事故になる

人が操作しない自動処理（CI）から Claude Code を動かすための、長く使える認証キーを発行します。これは家の合鍵そのもので、うっかりファイルに貼ってしまうと誰でもあなたの権限で使えてしまいます。作る必要が本当にあるか、置き場所をどうするかを必ず人に確認してから実行してください。

```
claude setup-token
```

### 🔴 `claude project purge`（クロード プロジェクト パージ）

**止めて確認**

**一言でいうと**: そのプロジェクトの会話履歴などを丸ごと消す

purge は「一掃する」という意味で、そのフォルダに紐づく会話履歴や設定の保存データを削除します。過去の会話に戻れなくなり、元に戻せません。書類棚を中身ごと処分するのと同じなので、実行前に必ず人に確認してください。--dry-run を付けると「何が消えるか」の下見だけができます。

```
claude project purge --dry-run
```

| オプション | 意味 |
| --- | --- |
| `--dry-run` | 実際には消さず、消える予定だけを見せる |

### 🟡 `claude mcp`（クロード エムシーピー）

**変わるが戻せる**

**一言でいうと**: 外部サービスとの接続口（MCP）を設定する

MCP は Claude を社外のサービスや社内の別システムにつなぐ差込口の規格です。つなぐと便利になりますが、そこを通ってデータが外に出る可能性があります。家のコンセントに知らない機器をつなぐのと同じで、何につなぐのかを分かってから使ってください。会話中は /mcp で状態を確認できます。

```
claude mcp
```

### 🟡 `--allowedTools`（アラウド ツールズ）

**変わるが戻せる**

**一言でいうと**: この道具だけは確認なしで使っていい、と先に許す

指定した操作については毎回の確認が出なくなります。「読むだけの操作」など安全なものに絞れば作業が快適になります。信頼できる相手にだけ合鍵を渡す発想ですが、範囲を広げすぎると確認の意味がなくなります。

```
claude --allowedTools "Read" "Bash(git log *)"
```

### 🟢 `--disallowedTools`（ディスアラウド ツールズ）

**見るだけ・安全**

**一言でいうと**: この操作は絶対にさせない、と禁止しておく

指定した操作を使えなくします。許可を広げるのではなく狭める方向なので、安全側の設定です。子どもの手が届かないところに刃物を置くのと同じ考え方です。

```
claude --disallowedTools "Edit"
```

### 🟡 `--background`（バックグラウンド）

**一言でいうと**: 作業中の Claude を止める。押しても書いた分は残る


### 📖 `CLAUDE.md`（クロード ドット エムディー）

**一言でいうと**: プロジェクトの申し送り事項を書いた案内書き

プロジェクトの入口に置くテキストで、Claude は毎回これを読んでから作業します。「日本語で書く」「この命名規則で」など、毎回言いたくない約束事を書いておきます。職場の壁に貼ってある業務ルールと同じ役割です。/init で自動生成、/memory で編集できます。

```
CLAUDE.md
```

### 📖 `~/.claude/CLAUDE.md`（ホーム ドット クロード クロード ドット エムディー）

**一言でいうと**: どのプロジェクトでも共通で効く、自分専用の約束事

~ は自分のホームフォルダを指します。ここに書いた内容は全プロジェクトで読まれるので、「必ず日本語で答えて」など自分の好みを一度書けば済みます。会社のルールと自分の手帳のメモを分けて持つイメージです。プロジェクト側の CLAUDE.md と併用されます。

```
~/.claude/CLAUDE.md
```

### 📖 `CLAUDE.local.md`（クロード ドット ローカル ドット エムディー）

**一言でいうと**: 自分の手元だけで効かせたい追記メモ

同じプロジェクトでも、チームに共有せず自分の環境だけで効かせたい指示を書く場所です。共有の掲示板ではなく机の上の付箋、という位置づけです。ファイル名に local が入っているものは基本的に「共有しない自分用」と覚えておくと分かりやすいです。

```
CLAUDE.local.md
```

### 📖 `.claude/settings.json`（ドット クロード セッティングス ジェイソン）

**一言でいうと**: プロジェクト共通の設定ファイル。チームで共有する

許可の規則、フック（自動で走る処理）、環境変数などを書く設定ファイルです。プロジェクトのフォルダに入れてチーム全員に同じ設定を効かせます。職場の共有設定です。とくに許可を緩める書き換えは影響が大きいので、勝手に変えず人に相談してください。

```
.claude/settings.json
```

### 📖 `.claude/settings.local.json`（ドット クロード セッティングス ドット ローカル ジェイソン）

**一言でいうと**: 自分の手元だけに効く設定。共有されない

同じプロジェクトの中で、自分の環境だけで有効にしたい設定を書きます。共有される settings.json より優先されます。共用パソコンの共通設定と、自分のユーザー設定の関係と同じです。

```
.claude/settings.local.json
```

### 📖 `~/.claude/settings.json`（ホーム ドット クロード セッティングス ジェイソン）

**一言でいうと**: どのプロジェクトでも効く、自分の基本設定

配色や編集方式（Vim風にするなど）、共通の許可設定をここに書きます。プロジェクトごとの設定より広く効く、いわば自分のパソコンの初期設定です。Windows では ~ は %USERPROFILE% を指します。

```
~/.claude/settings.json
```

### 📖 `.mcp.json`（ドット エムシーピー ジェイソン）

**一言でいうと**: このプロジェクトでつなぐ外部サービスの一覧表

MCP（外部サービスとの接続口）の設定をプロジェクト単位で書くファイルです。チームで共有されるので、誰かが追加すると全員の環境でその接続が使われます。共有の延長コードに新しい機器を差すのと同じで、何につながっているかを把握しておくことが大切です。

```
.mcp.json
```

### 📖 `.claude/agents/`（ドット クロード エージェンツ）

**一言でいうと**: 分担させる専門担当（サブエージェント）の定義置き場

「レビュー担当」「テスト担当」のように役割を書いたファイルを入れておくフォルダです。プロジェクト用は .claude/agents/、自分専用は ~/.claude/agents/ に置きます。部署ごとの業務分担表をファイル化したものと考えてください。

```
.claude/agents/reviewer.md
```

### 📖 `.claude/skills/`（ドット クロード スキルズ）

**一言でいうと**: よく使う手順書（スキル）を置くフォルダ

SKILL.md というファイルに手順を書いて置くと、/名前 で呼び出せるようになります。同じ説明を毎回貼り付けているなら、それは手順書にする合図です。よく作る料理をレシピカードにして箱に入れておく感覚で、必要なときだけ読み込まれます。

```
.claude/skills/deploy/SKILL.md
```

### 📖 `許可モード（permission mode）`（パーミッション モード）

**一言でいうと**: どこまで確認せずに進めさせるかの、6段階の構え

default（Manual、読むだけ自動）、acceptEdits（書き換えも自動）、plan（計画のみ）、auto（安全確認付きでほぼ全部）、dontAsk（事前に許した分だけ）、bypassPermissions（全部無確認）があります。新人への任せ方を段階で決めるのと同じです。bypassPermissions は隔離された環境専用で、通常業務では使いません。

```
画面下に「⏸ plan mode on」「⏵⏵ accept edits on」と表示される
```

### 📖 `コンテキストウィンドウ（context window）`（コンテキスト ウィンドウ）

**一言でいうと**: Claude が一度に覚えていられる話の量の上限

人が一度に頭に入れておける情報量に上限があるのと同じで、Claude にも会話を保持できる量の限界があります。これが埋まってくると /compact での要約や /clear でのやり直しが必要になります。机の広さに例えると、書類を広げすぎると新しい書類を置く場所がなくなる状態です。/context で残りを見られます。

```
/context
```

### 📖 `MCP（Model Context Protocol）`（エムシーピー）

**一言でいうと**: Claude を外部サービスにつなぐための共通の差込口

社内システムやクラウドサービスと Claude をつなぐ規格です。つなぐとその先のデータを読んだり操作したりできますが、逆に情報が外に出る経路にもなります。コンセントの形が世界共通なら色々な機器が差せる、という発想の仕組みです。設定は /mcp や .mcp.json で確認します。

```
/mcp
```
